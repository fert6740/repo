# Задания Фоксфорда (папка `Textbooks/` в корне репозитория)

Пользователь будет присылать задания (контрольные Фоксфорда). Учебники по предметам лежат в папке `Textbooks/`:
`Textbooks/<Предмет>/_Оглавление.txt` (список тем → имена файлов) и `Textbooks/<Предмет>/NNN Название.txt` (по файлу на тему).
Предметы: Английский язык, География, История, Литература, Обществознание, Русский язык, Физика, Химия.
У «Русского языка» темы лежат в подпапках `1/` и `2/` (в оглавлении пути указаны вместе с подпапкой).

## Правила работы

- Выполнять задания **аргументированно**: показывать ход рассуждений, а не только ответ.
- Главное — **чтобы каждая задача была решена верно**.
- **Если не уверен в ответе — сразу сообщать об этом.**
- **Если условие неясно — сразу сообщать**, не угадывать.
- Задачи между чатами **не связаны** — не опираться на предыдущие чаты.
- Уровень решения — **уровень ЕГЭ**.
- **Порядок работы над каждым заданием — всегда, без исключений:**
  1. Решить задание и дать **свой ответ**.
  2. **После этого проверить ВСЁ по учебнику** — каждый ответ, каждое утверждение, правило, термин, дату, формулу — даже если в ответе уверен:
     - найти в `Textbooks/<Предмет>/_Оглавление.txt` подходящие темы;
     - прочитать нужные файлы тем;
     - сверить с ними свой ответ.
  3. Написать итог проверки: **что подтвердилось, что исправлено** (если учебник расходится с ответом — объяснить, в чём, и дать исправленный ответ), а если в учебнике чего-то нет — прямо сказать об этом.
  4. **Назвать имена файлов**, по которым проверял.
  5. **В самом конце каждого ответа** — отдельный блок:
     - **Итоговый ответ:** окончательный ответ (после проверки по учебнику) в том виде, в каком его вписывать;
     - **Степень уверенности:** в процентах и словами (высокая / средняя / низкая) с кратким пояснением, что её снижает (если что-то снижает).
- Везде, где нужно что-то посчитать, — **использовать Python** (не считать в уме).
- Математику оформлять в **LaTeX**.
- Пересказ условия — только как пояснение «как я понял задачу», **решать всегда по исходному тексту**:
  - пересказ не должен добавлять, убирать или менять ничего по смыслу (числа, отрицания «НЕ», «неверно», «все/некоторые», формат ответа);
  - если пересказ без потери смысла невозможен — не пересказывать;
  - перед итоговым ответом сверить его с **исходным** условием (на тот ли вопрос отвечаю, в нужном ли формате);
  - если условие допускает два прочтения — не выбирать молча, а сразу сказать об этом.
