Формулы химических соединений могут быть изображены по-разному.




{**Структурная формула**}




форма записи, отображающая химическое строение (структуру) молекулы, составленная из символов химических элементов и специальных знаков (черточек), обозначающих взаимосвязь элементов в соответствии с их валентностью.






Для построения структурных формул необходимо знать валентность каждого элемента в рассматриваемом соединении.




{**Пространственная формула**}




структурная формула, отражающая расположение элементов в пространстве относительно друг друга.






Наиболее наглядной формой изображения молекулы является её шаростержневая модель:


[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/53861/47678157744f4081.png]

Попробуйте изготовить структурные формы молекул своими руками, это будет напоминать пазл.


## Что понадобится




- плотный разноцветный картон (бумага);

- ножницы;

- ручка (фломастеры).





## Как сделать:


1. Разлинуйте лист картона (плотной бумаги) на квадраты размером 1 см x 1 см.


[рисунок недоступен: Картинки по запросу разлинованный лист]


2. Габариты каждого пазла будут 5 x 5 (включая выступы). 3. Пазл с элементом, имеющим положительную степень окисления, будет иметь столько выступов, какова его степень окисления, например: [рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_image/image/48772/0.png]


4. Элемент с отрицательной степенью окисления будет иметь столько "впадин", каково значение его степени окисления. Например:


[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_image/image/48773/0.png]


5. Обратите внимание, что некоторые элементы имеют несколько степеней окисления. В таком случае понадобится несколько пазлов для одного элемента. Выполните их в одном цвете. Общепринятые цвета, используемые для обозначений элементов, приведены в таблице 1 (см. выше). [рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_image/image/48774/0.png]


6. Возможные степени окисления некоторых элементов представлены в таблице:

Для простейшего моделирования молекул можно также использовать конструктор «Лего»:


Принцип работы с конструктором аналогичен принципу построения химического пазла, описанному выше:




- каждый элемент имеет свой собственный цвет;

- каждый атом имеет свою степень окисления (валентность).



По возможности, выберите те детали, количество "палочек", в которых совпадает с валентностью. Например, для водорода выберите «единичный» кубик Лего, для кислорода — двойной кубик.


Если в вашем наборе недостаточное количество «кубиков» нужного размера, можно использовать более распространённые детали.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/44983/e56ac267d507fa7c.png] {**Изготовление шаростержневых моделей молекул**}




Пространственные модели молекул удобны в использовании и наглядно показывают расположение атомов элементов относительно друг друга и химические связи.


## Что понадобится:




- разноцветный пластилин, папье-маше или другой материал, подходящий для лепки;

- зубочистки или спички.



## Как сделать:




1) Сделайте заготовки атомов различных элементов. Для этого скатайте шарики из пластилина разного размера (учитывайте разные атомные радиусы). Каждому элементу соответствует свой собственный цвет (см. Табл. 1).


2) Выберите вещество, молекулу которого хотите построить (например, $H_2O$, $CH_4$, ($HCl, \ H_2SO_4, \ NaOH$ и т. д.). Определите валентность каждого элемента в этом веществе и постройте его структурную формулу.


3) Соедините «пластилиновые» атомы друг с другом зубочистками (спичками), исходя из значений валентностей.
