Неметаллы встречаются в природе преимущественно в виде соединений. В свободном состоянии в состав воздуха входят азот $N_2$, кислород $O_2$, благородные газы, в верхних слоях атмосферы в очень небольшом количестве содержится озон $O_3$. В природе в свободном состоянии встречаются также углерод и сера.


Не существует единого способа получения неметаллов. Рассмотрим важнейшие лабораторные и промышленные способы получения некоторых неметаллов. Промышленные способы получения веществ, как правило, сильно отличаются от лабораторных. Промышленное производство направлено на получение больших количеств максимально дешёвого продукта.




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7501/f2477ca7e8d30589.png] {**Получение водорода**}




Водород получают в лаборатории взаимодействием металлов с кислотами, например:


$Zn +2HCl = ZnCl_2 + H_2 \uparrow$


Промышленные способы получения водорода отличаются от лабораторных способов его получения. В промышленности водород получают по следующим реакциям:




- газопаровая конверсия угля:



$C + H_2O = CO + H_2$




- взаимодействие метана с водяным паром:



$CH_4 + H_2O = CO + 3H_2$




- разложение метана:



$CH_4 = C + 2H_2$




- электролиз воды:



$2H_2O = 2H_2 + O_2$




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7501/f2477ca7e8d30589.png] {**Получение галогенов**}




Галогены получают путем окисления галогеноводородных кислот:


$MnO_2 + 4HCl = MnCl_2 + Cl_2 \uparrow + 2H_2O$


$K_2Cr_2O_7 + 14HCl = 3Cl_2 \uparrow + 2KCl + 2CrCl_3 + 7H_2O$


$2KMnO_4 + 16HCl = 2MnCl_2 + 5Cl_2 \uparrow + 8H_2O + 2KCl$


Промышленное получение фтора и хлора основано на электролизе: фтор получают исключительно электролизом расплавов фторидов металлов, хлор — расплавов и растворов хлоридов:


$2KF = 2K + F_2$
расплав


$2NaCl = 2Na + Cl_2$
расплав


$2NaCl + 2H_2O = 2NaOH + H_2 + Cl_2$


Бром и иод получают путём окисления бромидов и иодидов хлором, например:


$2NaBr + Cl_2 = 2NaCl + Br_2$




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7501/f2477ca7e8d30589.png] {**Получение кислорода**}




Для получения кислорода в лаборатории используют реакции термического разложения кислородсодержащих сложных веществ, например:


$2KMnO_4 = K_2MnO_4 + MnO_2 + O_2 \uparrow$


$4K_2Cr_2O_7 = 4K_2CrO_4 + 2Cr_2O_3 + 3O_2 \uparrow$


$2H_2O_2 = 2H_2O + O_2 \uparrow$


В промышленности кислород получают из сжиженного воздуха. Воздух охлаждают примерно до $–200^{\circ} C$. При этой температуре воздух представляет собой жидкость голубоватого цвета. Затем жидкий воздух медленно нагревают, в результате чего начинается процесс испарения газов в последовательности, соответствующей увеличению их температур кипения: сначала выделяется азот, имеющий самую низкую температуру кипения ($t_{кип} = –196^{\circ} C$}, затем аргон ($t_{кип} = –189^{\circ} C$), потом кислород ($t_{кип} = –183^{\circ} C$).




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7501/f2477ca7e8d30589.png] {**Получение серы**}




Серу получают неполным окислением сероводорода или путём взаимодействия сернистого газа с сероводородом:


$2H_2S + O_2 = 2S + 2H_2O$


$2H_2S + SO_2 = 3S \downarrow + 2H_2O$


В промышленности самородную серу извлекают из пластов, которые она образует между осадочными породами, с помощью водяного пара. Другим источником серы является сероводород, содержащийся в газах, которые сопутствуют нефти.




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/83195/4d2340e80664d89e.png] {**Получение азота**}




Для получения азота используют реакцию разложения нитрита аммония:


$NaNO_2 + NH_4Cl = N_2 \uparrow + NaCl + 2H_2O$


В промышленности азот получают из жидкого воздуха при его фракционной перегонке. Азот, имеющий самую низкую температуру кипения ($t_{кип} = –196^{\circ} C$) из входящих в состав воздуха газов, выделяется первым.




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7501/f2477ca7e8d30589.png] {**Получение фосфора**}




Фосфор получают в промышленности путём нагревания фосфата кальция с углём и оксидом кремния(IV) без доступа воздуха:


$Ca_3(PO_4)_2 + 3SiO_2 + 5C = 3CaSiO_3 + 5CO + 2P$




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7501/f2477ca7e8d30589.png] {**Получение кремния**}




Кремний получают в промышленности из кремнезема $SiO_2$ восстановлением магнием или углеродом (коксом):


$SiO_2 + 2Mg = Si + 2MgO$


$SiO_2 + 2C = Si + 2CO$


Чистый кремний получают восстановлением тетрахлорида кремния водородом при $1200^{\circ} C$:


$SiCl_4 + 2H_2 = Si + 4HCl$


или термическим разложение силана:


$SiH_4 = Si + 2H_2$




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7501/f2477ca7e8d30589.png] {**Получение селена, теллура, мышьяка и бора**}




Селен и теллур получают из отходов производства серной кислоты, так как эти элементы сопутствуют в природе соединениям серы.


Мышьяк получают обжигом сульфидных руд с последующим восстановлением полученного оксида углем:


$2As_2S_3 + 9O_2 = 6SO_2 + 2As_2O_3$


$As_2O_3 + 3C = 2As + 3CO$


Бор получают восстановлением оксида бора магнием


$B_2O_3 + 3Mg = 3MgO + 2B$
