Для средних солей характерны следующие химические свойства:

**1. Реакции обмена**

Средние соли способны вступать в реакции обмена с кислотами, щелочами, другими солями, если в результате реакции образуется осадок, газ или слабый электролит (например, вода).

– Взаимодействие с кислотами:

$AgNO_3 + HCl = AgCl \downarrow + HNO_3$

$CaCO_3 + 2HNO_3 = Ca(NO_3)_2 + CO_2 \uparrow + H_2O$

– Взаимодействие с щелочами:

$Fe(NO_3)_3 + 3NaOH = Fe(OH)_3 \downarrow + 3NaNO_3$

$NH_4Cl + KOH = NH_3 \uparrow + H_2O + KCl$

– Взаимодействие с другими солями:

$CaCl_2 + Na_2SiO_3 = CaSiO_3 \downarrow + 2NaCl$

**2. Реакции замещения**

Соли способны вступать в реакции замещения при взаимодействии с металлами.

В водном растворе соли взаимодействуют с металлами, стоящими в электрохимическом ряду напряжений левее, чем металл, входящий в состав соли, например:

$CuSO_4 + Fe = Cu \downarrow + FeSO_4$

Но сульфат цинка не взаимодействует с железом, так как железо менее активно, чем цинк (железо стоит в электрохимическом ряду напряжений после цинка):

$ZnSO_4 + Fe \ne $

Однако активные металлы — щелочные и щёлочноземельные — в водных растворах солей будут вступать в реакцию не с солью, а с водой.

**3. Термическое разложение (например, карбонатов, нитратов, солей аммония)**

– Нерастворимые карбонаты и карбонат лития разлагаются на оксид металла и углекислый газ $CO_2$:

$CaCO_3 = CaO + CO_2 \uparrow$

Продуктами разложения карбоната аммония являются углекислый газ, аммиак и вода:

$(NH_4)_2CO_3 = 2NH_3 \uparrow + CO_2 \uparrow + H_2O$

– Разложение нитратов металлов происходит в соответствии с положением металла в электрохимическом ряду напряжений:

| Металл | Левее $Mg$, кроме $Li$ | От $Mg$ до $Cu$ (вкл.) | Правее $Cu$ |
| Схема | $MeNO_3 \rightarrow MeNO_2$ + / $O_2 \uparrow$ Нитрит | $MeNO_3 \rightarrow Me_xO_y$ + / $NO_2 \uparrow + O_2 \uparrow$ / Оксид / металла | $MeNO_3 \rightarrow Me$ + / $NO_2 \uparrow + O_2 \uparrow$ / Металл |
| Пример | $2KNO_3 = 2KNO_2 + O_2$ | $2Cu(NO_3)_2 = 2CuO$ + / $4NO_2 + O_2$ | $2AgNO_3 = 2Ag$ + / $2NO_2 + O_2$ |

Нитрат аммония разлагается с образованием оксида азота($I$) и воды:

$NH_4NO_3 = N_2O \uparrow + 2H_2O$

– Термическое разложение солей аммония происходит с образованием аммиака $NH_3$:

$NH_4Cl = NH_3 \uparrow + HCl \uparrow$

Разложение солей аммония, в состав которых входит анион, проявляющий окислительные свойства, сопровождается выделением азота или оксида азота($I$):

$(NH_4)_2Cr_2O_7 = N_2 \uparrow + Cr_2O_3 + 4H_2O$

$NH_4NO_3 =N_2O \uparrow + 2H_2O$

$NH_4NO_2 =N_2 \uparrow + 2H_2O$

– Хлорат калия в присутствии катализатора (например, $MnO_2$) разлагается с образованием хлорида калия и выделением кислорода:

$2KClO_3 = 2KCl + 3O_2­ \uparrow$

В отсутствие катализатора хлорат калия при нагревании диспропорционирует с образованием хлорида и перхлората калия:

$4KClO_3 = KCl + 3KClO_4$

**4. Некоторые соли в водном растворе подвергаются гидролизу**

(см. тему «Гидролиз солей»)

Кислые соли можно рассматривать как продукт неполного замещения атомов водорода в многоосновных кислотах на атомы металла.

**1. Взаимодействие с щелочами**

Наличие катионов водорода в составе кислых солей обусловливает их способность взаимодействовать с щелочами с образованием средних солей, например:

$NaHCO_3 + NaOH = Na_2CO_3 + H_2O$

$KHSO_4 + KOH = K_2SO_4 + H_2O$

Дигидрофосфаты при взаимодействии c щелочами в зависимости от соотношения реагентов способны переходить в фосфаты, например:

$NaH_2PO_4 + 2NaOH = Na_3PO_4 + 2H_2O$

**2. Кислые соли разлагаются при нагревании**

Так, при нагревании гидрокарбонаты переходят в карбонаты, выделяя углекислый газ и воду, например:

$2NaHCO_3 = Na_2CO_3 + CO_2 \uparrow + H_2O$

$Ca(HCO_3)_2 = CaCO_3 \downarrow + CO_2 \uparrow + H_2O$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8698/c5bf3e653a429f6e.png] {**Особенности химических свойств основных солей**}

Основные соли можно рассматривать как продукт неполного замещения гидроксо-групп в многокислотных основаниях на анион кислотного остатка.

**1. Взаимодействие с кислотами**

Наличие гидроксид-ионов в составе основных солей обусловливает их способность взаимодействовать с кислотами с образованием средних солей. Основные соли взаимодействуют с кислотами с образованием средних солей, например:

$Sn(OH)Cl + HCl = SnCl_2 + H_2O$

**2. Основные соли разлагаются при нагревании**

Например:

$(CuOH)_2CO_3 = 2CuO + CO_2 \uparrow + H_2O$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8698/c5bf3e653a429f6e.png] {**Химические свойства комплексных солей (на примере соединений алюминия и цинка)**}

Для комплексных солей алюминия и цинка характерны следующие химические свойства:

**1. При взаимодействии с избытком сильных кислот**

При действии избытка сильной кислоты комплексные соли разрушаются с образованием двух средних солей:

$Na[Al(OH)_4] + 4HCl_{(изб.)} = NaCl + AlCl_3 + 4H_2O$

$Na_2[Zn(OH)_4] + 4HCl = 2NaCl + ZnCl_2 + 4H_2O$

**2. При взаимодействии с недостатком сильных кислот**

При действии сильной кислоты, взятой в недостатке, образуются средняя соль активного металла, амфотерный гидроксид и вода:

$Na[Al(OH)_4] + HCl = NaCl + Al(OH)_3 \downarrow + H_2O$

$Na_2[Zn(OH)_4] + 2HCl = 2NaCl + Zn(OH)_2 \downarrow + 2H_2O$

**3. Взаимодействие с сероводородами**

Сероводород осаждает из тетрагидроксоалюмината гидроксид алюминия:

$Na[Al(OH)_4] + H_2S = NaHS + Al(OH)_3 \downarrow + H_2O$

Однако при взаимодействии тетрагидроксоцинката с сероводородом осаждается не гидроксид, а сульфид цинка $ZnS$:

$Na_2[Zn(OH)_4] + 3H_2S = 2NaHS + ZnS \downarrow + 4H_2O$

**4. Взаимодействие с углекислым газом**

При действии углекислого или сернистого газа происходит разрушение комплексной соли и осаждение амфотерного гидроксида:

$Na[Al(OH)_4] + CO_2 = NaHCO_3 + Al(OH)_3 \downarrow$

$Na_2[Zn(OH)_4] + 2CO_2 = 2NaHCO_3 + Zn(OH)_2 \downarrow$

**5. Разложение при прокаливании**

Гидроксокомплексы щелочных металлов при прокаливании разлагаются с образованием метаалюмината и цинката соответственно:

$Na[Al(OH)_4] = NaAlO_2 + 2H_2O$

$Na_2[Zn(OH)_4] = Na_2ZnO_2 + 2H_2O$

**6. При действии солей, образованных сильными кислотами и катионами $Fe^{3+}, Al^{3+}$ и $Cr^{3+}$,** вследствие взаимного усиления гидролиза получаются два амфотерных гидроксида:

$3Na[Al(OH)_4] + FeCl_3 = 3Al(OH)_3 \downarrow + Fe(OH)_3 \downarrow + 3NaCl$

$3Na_2[Zn(OH)_4] + 2AlCl_3 = 3Zn(OH)_2 \downarrow + 2Al(OH)_3 \downarrow + 6NaCl$

Для средних солей характерны следующие реакции: реакции обмена с кислотами, щелочами, другими солями, если в результате реакции образуется осадок, газ или слабый электролит (например, вода); реакции замещения в водном растворе с металлами, стоящими в электрохимическом ряду напряжений левее, чем металл, входящий в состав соли; некоторые соли разлагаются при нагревании.

Наличие катионов водорода в составе кислых солей обусловливает их способность взаимодействовать с щелочами с образованием средних солей.

Наличие гидроксид-ионов в составе основных солей обусловливает их способность взаимодействовать с кислотами с образованием средних солей.

Комплексные соли алюминия и цинка разрушаются под действием кислот, солей $Fe^{3+}$, $Al^{3+}$ и $Cr^{3+}$ и при нагревании.

Средние соли можно получить, используя следующие реакции:

1. Взаимодействие металла с неметаллом (получение солей бескилородных кислот):

$2Na + Cl_2 = 2NaCl$

2. Взаимодействие металла с кислотой:

$Zn + 2HCl = ZnCl_2 + H_2 \uparrow$

3. Взаимодействие металла с раствором соли менее активного металла. Более активные металлы, расположенные в ряду активности левее, способны вытеснять менее активные (расположенные правее) металлы из их солей:

$Fe + CuSO_4 = FeSO_4 + Cu$

4. Взаимодействие основного оксида с кислотным оксидом:

$MgO + CO_2 = MgCO_3$

5. Взаимодействие основного оксида с кислотой:

$CuO + H_2SO_4= CuSO_4 + H_2O$

6. Взаимодействие основания с кислотным оксидом:

$Ba(OH)_2+ CO_2 = BaCO_3 + H_2O$

7. Реакции ионного обмена, а именно:

- основания с кислотой,

- соли с кислотой,

- раствора основания с раствором соли,

- растворов двух солей.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8750/93dcf093e609486b.png] {**Получение кислых солей**}

Для получения кислых солей необходимы условия, при которых обеспечивается увеличение концентрации ионов водорода $H^+$. Поэтому кислые соли получают, используя следующие реакции:

1. Взаимодействие кислоты с недостатком основания:

$KOH + H_2SO_4 = KHSO_4 + H_2O$

2. Взаимодействие основания с избытком кислотного оксида:

$Ca(OH)_2 + 2CO_2 = Ca(HCO_3)_2$

3. Взаимодействие средней соли с кислотой:

$Ca_3(PO_4)_2 + 4H_3PO_4 = 3Ca(H_2PO_4)_2$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8750/93dcf093e609486b.png] {**Получение основных солей**}

Для получения основных солей, наоборот, необходимо обеспечить условия, при которых увеличивается концентрация анионов гидроксогруппы $OH^–$. К таким условиям относятся:

1. Гидролиз солей, образованных слабым основанием и сильной кислотой

$ZnCl_2+ H_2O = [Zn(OH)]Cl + HCl$

2. Добавление (по каплям) небольших количеств щелочей к растворам средних солей металлов:

$AlCl_3 + 2NaOH = [Al(OH)_2]Cl + 2NaCl$

3. Взаимодействие солей слабых кислот со средними солями:

$2MgCl_2 + 2Na_2CO_3 + H_2O = [Mg(OH)]_2CO_3 + CO_2 + 4NaCl$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8750/93dcf093e609486b.png] {**Получение комплексных солей**}

Приведём примеры получения некоторых комплексных солей из средних солей в результате реакций соединения и обмена:

$HgI_2 + 2KI$ (изб.) = $K_2[HgI_4]$;

$CuSO_4 + 4NH_4OH = [Cu(NH_3)_4]SO_4 + 4H_2O$;

$ZnCl_2 + 4NaOH$ (изб.) = $Na_2[Zn(OH)_4] + 2NaCl$.

$AgCl + 2NH_3 = [Ag(NH_3)_2]Cl$;

$FeCl_3 + 6KCN = K_3[Fe(CN)_6] + 3KCl$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8750/93dcf093e609486b.png] {**Получение двойных солей**}

Двойные соли можно получить путём совместной кристаллизации двух солей:

$Cr_2(SO_4)_3 + K_2SO_4 + 24H_2O = 2[KCr(SO_4)_2 \cdot 12H_2O] \downarrow$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8750/93dcf093e609486b.png] {**Химические свойства комплексных солей**}

1. Разрушение комплексов за счёт образования малорастворимых соединений:

$2[Cu(NH_3)_2]Cl + K_2S = Cu_2S \downarrow + 2KCl + 4NH_3 \uparrow$

2. Обмен лигандами между внешней и внутренней сферами:

$K_2[CoCl_4] + 6H_2O = [Co(H_2O)_6]Cl_2+ 2KCl$

$KCr(SO_4)_2 + 3KOH = Cr(OH)_3 + 2K_2SO_4$
