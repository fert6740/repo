- Метод полуреакций (ионно-электронный)

- Примеры расстановки коэффициентов методом полуреакций в окислительно-восстановительных реакциях с участием неорганических и органических веществ

Для расстановки коэффициентов в ОВР используют различные методы, среди которых наиболее часто применяют метод электронного баланса и метод полуреакций. В основе всех методов расстановки коэффициентов в ОВР лежит правило:

**Общее число электронов, отданных восстановителем, должно быть равно общему числу электронов, принятых окислителем**.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8698/c5bf3e653a429f6e.png] **Метод полуреакций (ионно-электронный)**

Метод полуреакций, или ионно-электронный, даёт более правильное представление об окислительно-восстановительных процессах, протекающих в растворах. В этом методе не надо определять степень окисления элементов.

Преимущество метода ионно-электронного баланса состоит также в том, что с его помощью легко можно расставить все стехиометрические коэффициенты в полном уравнении окислительно-восстановительной реакции.

Однако у метода полуреакций есть свои ограничения, которые надо обязательно учитывать: метод полуреакций не применяют для расстановки коэффициентов в окислительно-восстановительных реакциях, протекающих в не водной среде.

В методе полуреакций при составлении уравнений ОВР следует придерживаться той же формы записи, что и для уравнений реакций ионного обмена, а именно: в виде ионов записывают формулы сильных электролитов (сильных кислот, щелочей, растворимых средних солей); в молекулярной форме записывают формулы малорастворимых, малодиссоциирующих и газообразных соединений.

Используя метод полуреакций, практически всегда приходится сталкиваться с необходимостью уравнять число атомов кислорода в левой и правой части схемы полуреакции. В зависимости от среды – кислой, нейтральной или щелочной – при уравнивании числа атомов кислорода нужно учитывать следующие правила:

- В кислых средах избыток кислорода в исходных веществах по сравнению с продуктами связывается ионами водорода с образованием молекул воды, например:

$MnO_4^– + 8H^+ + 5e^– = Mn^{2+} + 4H_2O$

$Cr_2O_7^{2–} + 14H^+ + 6e^– = 2Cr^{3+} + 7H_2O$

- В нейтральных и щелочных средах избыток кислорода связывается молекулами воды с образованием гидроксид-ионов, например:

$MnO_4^– + 2H_2O + 3e^– = MnO_2 \downarrow + 4OH^–$

- При недостатке кислорода в кислой и нейтральной среде присоединение кислорода осуществляется за счёт молекул воды и сопровождается образованием ионов водорода, например:

$I_2 + 6H_2O – 10e^– = 2IO_3^– + 12H^+$

- При недостатке кислорода в щелочной среде присоединение кислорода происходит за счет гидроксид-ионов с образованием молекул воды, например:

$[Cr(OH)_4]^– + 4OH^– – 3e^– = CrO_4^{2–} + 4H_2O$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/82737/c6d94096de3fcbec.png] **Примеры расстановки коэффициентов методом полуреакций в окислительно-восстановительных реакциях с участием неорганических и органических веществ**

Приведём примеры расстановки коэффициентов в уравнениях окислительно-восстановительных реакций методом полуреакций с учётом рассмотренных правил.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] **Пример 1**

Окисление нитрита натрия перманганатом калия в кислой среде

Составим схему реакции:

$NaNO_2 + KMnO_4 + H_2SO_4 \rightarrow NaNO_3 + MnSO_4 + K_2SO_4 + H_2O$

Составим полуреакции окисления нитрит-иона и восстановления перманганат-иона с учётом содержания в них атомов кислорода и характера среды.

В ходе реакции нитрит-ион окисляется до нитрат-иона, недостающие атомы кислорода берутся из воды, в результате освобождаются ионы водорода:

$NO_2^– + H_2O \rightarrow NO_3^– + 2H^+$

В кислой среде перманганат-ион восстанавливается до катиона $Mn^{2+}$, избыток кислорода связывается ионами водорода с образованием молекул воды:

$MnO_4^– + 8H^+ = Mn^{2+} + 4H_2O$

Суммарное число зарядов продуктов полуреакции должно быть равно суммарному числу зарядов исходных веществ. Сравнивая суммарный заряд частиц в правой и левой части полуреакций, делаем вывод, что один нитрат-ион при окислении отдаёт $2$ электрона, а один перманганат-ион при восстановлении присоединяет $5$ электронов:

$NO_2^– + H_2O –2e^– \rightarrow NO_3^– + 2H^+$

$MnO_4^– + 8H^+ + 5e^– = Mn^{2+} + 4H_2O$

Умножаем первую полуреакцию на $5$, вторую — на $2$:

$NO_2^– + H_2O –2e^– = NO_3^– + 2H^+ |5|$

$MnO_4^– + 8H^+ + 5e^– = Mn^{2+} + 4H_2O |2|$

Суммируем полуреакции:

$5NO_2^– + 5H_2O –10e^– = 5NO_3^– + 10H^+$

$2MnO_4^– + 16H^+ + 10e^– = 2Mn^{2+} + 8H_2O$

$5NO_2^– + 5H_2O + 2MnO_4^– + 16H^+ = 5NO_3^2 + 10H^+ + 2Mn^{2+} + 8H_2O$

Сокращаем одинаковые ионы и молекулы в левой и правой частях уравнения и получаем: уравнение в ионном виде:

$5NO_2^– + 2MnO_4^– + 6H^+ = 5NO_3^– + 2Mn^{2+} + 3H_2O$

Дописываем недостающие ионы $Na^+, K^+ и SO_4^{2–}$ и получаем молекулярное уравнение:

$5NaNO_2 + 2KMnO_4 + 3H_2SO_4 = 5NaNO_3 + 2MnSO_4 + K_2SO_4 + 3H_2O$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] **Пример 2**

Окисление нитрита натрия перманганатом калия в щелочной среде

Составим схему реакции:

$NaNO_2 + KMnO_4 + KOH \rightarrow NaNO_3 + K_2MnO_4 + H_2O$

Составим полуреакции окисления нитрит-иона и восстановления перманганат-иона с учётом содержания в них атомов кислорода и характера среды:

$NO_2^– + 2OH^– – 2e^– = NO_3^– + H_2O |1|$

$MnO_4^– + e^– = MnO_4^{2–} |2|$

$NO_2^– + 2OH^– + 2MnO_4^– = NO_3^– + H_2O + 2MnO_4^{2–}$

Дописываем недостающие ионы $Na^+$ и $K^+$ и получаем молекулярное уравнение реакции:

$NaNO_2 + 2KMnO_4 + 2KOH = NaNO_3 + 2K_2MnO_4 + H_2O$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] **Пример 3**

Окисление нитрита натрия перманганатом калия в нейтральной среде

Составим схему реакции:

$NaNO_2 + KMnO_4 + H_2O \rightarrow NaNO_3 + MnO_2 \downarrow + KOH$

Составим полуреакции окисления нитрит-иона и восстановления перманганат-иона с учётом содержания в них атомов кислорода и среды. Учтём, что в результате реакции образуется щёлочь, поэтому составим электронно-ионное уравнение реакции, считая, что в реакции участвуют молекулы воды и гидроксид-ионы:

$NO_2^– + H_2O – 2e^– NO_3^– + 2H^+ |3|$

$MnO_4^– + 2H_2O + 3e^– MnO_2 + 4OH^– |2|$

$3NO_2^– + 3H_2O + 2MnO_4^– + 4H_2O = 3NO_3^– + 6H^+ + 2MnO_2 + 8OH^–$

Суммируем молекулы воду, ионы $H^+$ и $OH^–$ образуют молекулы воды:

$3NO_2^– + 2MnO_4^– + 7H_2O = 3NO_3^– + 6H_2O + 2MnO_2 \downarrow + 2OH^–$

Сокращаем одинаковые ионы и молекулы в левой и правой частях уравнения и получаем: уравнение в ионном виде:

$3NO_2^– + 2MnO_4^– + H_2O = 3NO_3^– + 2MnO_2 \downarrow + 2OH^–$

Дописываем недостающие ионы $Na^+$ и $K^+$ и получаем молекулярное уравнение реакции:

$3NaNO_2 + 2KMnO_4 + H_2O = 3NaNO_3 + 2MnO_2 \downarrow + 2KOH$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] **Пример 4**

Реакция окисления сульфида мышьяка($III$) концентрированной азотной кислотой

В ходе реакции одна молекула $As_2S_3$ превращается в две молекулы ортомышьяковой кислоты $H_3AsO_4$ и три иона $SO_4^{2–}$; ортомышьяковая кислота — кислота средней силы, поэтому её формулу можно записать в молекулярном виде:

$As_2S_3 \rightarrow 2H_3AsO_4 + 3SO_4^{3–}$

Источником кислорода в кислой среде являются молекулы воды. Для образования двух молекул $H_3AsO_4$ необходимо $8$ молекул $H_2O$, а для образования трёх ионов $SO_4^{2–}$ — $12$ молекул $H_2O$. Следовательно, в полуреакции окисления примут участие $20$ молекул $H_2O$, при этом образуется $40$ ионов $H^+$:

$As_2S_3 + 20H_2O = 2H_3AsO_4 + 3SO_4^{2–} + 34H^+$

Сравнивая суммарный заряд частиц в правой и левой частях полуреакции, делаем вывод, что при окислении одна молекулы $As_2S_3$ отдаёт $28$ электронов:

$As_2S_3 + 20H_2O – 28e^– = 2H_3AsO_4 + 3SO_4^{2–} + 34H^+$

При составлении полуреакции восстановления исходим из схемы:

$NO_3^– \rightarrow NO$

Процесс протекает в кислой среде, при этом избыток кислорода связывается ионами $H^+$ с образованием молекул воды:

$NO_3^– + 4H^+ = NO + 2H_2O$

Сравнивая суммарный заряд частиц в правой и левой части полуреакции, делаем вывод, что для восстановления одного иона $NO_3^-$ необходимо $3$ электрона:

$NO_3^– + 4H^+ + 3e^– = NO + 2H_2O$

Умножаем первую полуреакцию на $3$, вторую — на $28$, после чего суммируем их:

$As_2S_3 + 20H_2O – 28e^– = 2H_3AsO_4 + 3SO_4^{2–} + 34H^+ |3|$

$NO_3^– + 4H^+ + 3e^– = NO + 2H_2O$ |28|

$3As_2S_3$ + __$60H_2O$__ + $28NO_3^–$ + __$112H^+$__ = $6H_3AsO_4$ + __$102H^+$__ + $9SO_4^{2–}$ + __$56H_2O$__

После приведения подобных членов в обеих частях уравнения получим:

$3As_2S_3 + 28NO_3^– + 10H^+ + 4H_2O = 6H_3AsO_4 + 9SO_4^{2–} + 28NO$,

$+$ $+$

$18H^+$ $18H^+$

Добавляем, как показано, недостающие ионы $H^+$ и получаем молекулярное уравнение:

$3As_2S_3 + 28HNO_3 + 4H_2O \rightarrow 6H_3AsO_4 + 9H_2SO_4 + 28NO$

Если ОВР протекает не в водной среде, метод полуреакций использовать не рекомендуется, следует воспользоваться методом электронного баланса. Метод полуреакций очень удобен при расстановке коэффициентов в ОВР с участием органических веществ в водных средах.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] **Пример 5.** Рассмотрим процесс окисления пропена перманганатом калия $KMnO_4$ в кислой среде.

Составим две полуреакции с учётом характера среды. Будем придерживаться следующего алгоритма:

1. Составим схему полуреакции окисления:

$CH_3–CH=CH_2 \rightarrow CH_3–COOH + CO_2$

2. Уравняем число атомов кислорода в левой и правой части схемы полуреакции окисления с учётом среды. Источником кислорода в кислой среде являются молекулы воды. Образовавшиеся в результате окисления одной молекулы пропена одна молекула уксусной кислоты и одна молекула углекислого газа содержат $4$ атома кислорода. Следовательно, в полуреакции окисления примут участие $4$ молекулы $H_2O$:

$CH_3–CH=CH_2 + 4H_2O \rightarrow CH_3–COOH + CO_2$

3. Уравняем число атомов водорода в левой и правой части схемы полуреакции окисления. В левой части схемы содержится $14$ атомов водорода, в правой — только $4$; следовательно, в результате процесса окисления высвобождается $14 – 4 = 10$ ионов $H^+$:

$CH_3–CH=CH_2 + 4H_2O \rightarrow CH_3–COOH + CO_2 + 10H^+$

4. Сравним суммарный заряд частиц в левой и правой части схемы полуреакции окисления. Левая часть схемы содержит только незаряженные частицы, суммарный заряд в правой части равен $+10$. Следовательно, молекула пропена при окислении отдаёт $10$ электронов:

$CH_3–CH=CH_2 + 4H_2O – 10 \bar{e} \rightarrow CH_3–COOH + CO_2 + 10H^+$

5. Составим схему полуреакции восстановления:

$MnO_4^– \rightarrow Mn^{2+}$

6. Уравняем число атомов кислорода в левой и правой части схемы полуреакции восстановления с учётом среды. Процесс протекает в кислой среде, при этом избыток кислорода связывается ионами $H^+$: для связывания $4$ атомов кислорода необходимо $8$ ионов $H^+$, в результате чего образуется $4$ молекулы $H_2O$:

$MnO_4^– + 8H^+ \rightarrow Mn^{2+} + 4H_2O$

7. Сравним суммарный заряд частиц в левой и правой части схемы полуреакции восстановления. Вычислим суммарный заряд частиц в левой части схемы: $–1 + 8 \cdot (+1) = +7$. В правой части схемы суммарный заряд равен $+2$, следовательно, для восстановления одного иона $MnO_4^-$ необходимо $5$ электронов:

$MnO_4^– + 8H^+ + 5 \bar{e} \rightarrow Mn^{2+} + 4H_2O$

8. Суммируем уравнения полуреакций с учётом коэффициентов. Для этого находим наименьшее общее кратное числа отданных ($–10 \bar{e}$) и принятых ($+ 5 \bar{e}$) электронов, которое равно $10$. Значит, первую полуреакцию надо умножить на $1$, а вторую — на $2$:

$CH_3–CH=CH_2 + 4H_2O – 10 \bar{e} \rightarrow CH_3–COOH + CO_2 + 10H^+ |1|$

$MnO_4^– + 8H^+ + 5 \bar{e} \rightarrow Mn^{2+} + 4H_2O |2|$

$CH_3–CH=CH_2 + 4H_2O + 2MnO_4^– + 16H^+ \rightarrow CH_3–COOH + CO_2 + 10H^+ + 2Mn^{2+} + 8H_2O$

Приводим подобные члены в обеих частях уравнения и получаем:

$CH_3–CH=CH_2 + 2MnO_4^– + 6H^+ \rightarrow CH_3–COOH + CO_2 \uparrow + 2Mn^{2+} + 4H_2O$

9. Составим полное уравнение реакции, для чего в левую и правую части уравнения вводим недостающие катионы калия и сульфат-анионы:

$CH_3–CH=CH_2 + 2KMnO_4 + 3H_2SO_4 \rightarrow CH_3–COOH + CO_2 \uparrow + 2MnSO_4 + K_2SO_4 + 4H_2O$

10. Проверим правильность расстановки коэффициентов по числу атомов кислорода: в левой части — $20$, в правой части — $20$. Следовательно, коэффициенты расставлены верно.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] **Пример 6.** Покажем, как методом полуреакций расставить коэффициенты в реакции окисления пропена перманганатом калия $KMnO_4$ в нейтральной среде. Будем использовать тот же алгоритм действий.

1. Составим схему полуреакции окисления:

$CH_3–CH=CH_2 \rightarrow CH_3–CH(OH)–CH_2(OH)$

2. Уравняем число атомов кислорода в левой и правой части схемы полуреакции окисления с учётом среды. Источником кислорода в нейтральной среде, как и в кислой, являются молекулы воды. Образовавшаяся в результате окисления молекулы пропена молекула пропандиола–$1,2$ содержит $2$ атома кислорода. Следовательно, в полуреакции окисления примут участие $2$ молекулы $H_2O$:

$CH_3–CH=CH_2 + 2H_2O \rightarrow CH_3–CH(OH)–CH_2(OH)$

3. Уравняем число атомов водорода в левой и правой части схемы полуреакции окисления. В левой части схемы содержится на $2$ атома водорода больше, чем в правой; следовательно, в результате процесса окисления высвобождается $2$ иона $H^+$:

$CH_3–CH=CH_2 + 2H_2O \rightarrow CH_3–CH(OH)–CH_2(OH) + 2H^+$

4. Сравним суммарный заряд частиц в левой и правой части схемы полуреакции окисления. Левая часть схемы содержит только незаряженные частицы, суммарный заряд в правой части равен $+2$. Следовательно, молекула пропена при окислении отдает $2$ электрона:

$CH_3–CH=CH_2 + 2H_2O – 2 \bar{e} \rightarrow CH_3–CH(OH)–CH_2(OH) + 2H^+$

5. Составим схему полуреакции восстановления:

$MnO_4^– \rightarrow MnO_2$

6. Уравняем число атомов кислорода в левой и правой части схемы полуреакции восстановления с учётом среды. Процесс протекает в нейтральной среде, при этом избыток кислорода связывается молекулами воды $H_2O$ с образованием гидроксид-ионов $OH^–$. Прибавим молекулы $H_2O$ в левую часть схемы, а в правую — гидроксид-ионы $OH^–$. Затем уравняем число атомов кислорода и водорода в обеих частях схемы полуреакции. Для этого поставим перед формулой воды $H_2O$ коэффициент $2$, а перед формулой гидроксид-ионов $OH^–$ коэффициент $4$:

$MnO_4^– + 2H_2O \rightarrow MnO_2 + 4OH^–$

7. Сравним суммарный заряд частиц в левой и правой части схемы полуреакции восстановления. Суммарный заряд частиц в левой части схемы равен $–1$, в правой части суммарный заряд составляет $4 \cdot (–1) = –4$. Следовательно, для восстановления одного иона $MnO_4^-$ необходимо $3$ электрона:

$MnO_4^– + 2H_2O + 3 \bar{e} \rightarrow MnO_2 + 4OH^–$

8. Суммируем уравнения полуреакций с учётом коэффициентов. Для этого находим наименьшее общее кратное числа отданных ($–2 \bar{e}$) и принятых ($+ 3 \bar{e}$) электронов, которое равно $6$. Значит, первую полуреакцию надо умножить на $3$, а вторую — на $2$:

$CH_3–CH=CH_2 + 2H_2O – 2 \bar{e} \rightarrow CH_3–CH(OH)–CH_2(OH) + 2H^+ |3|$

$MnO_4^– + 2H_2O + 3 \bar{e} \rightarrow MnO_2 + 4OH^– |2|$

$3CH_3–CH=CH_2 + 6H_2O + 2MnO_4^– + 4H_2O \rightarrow 3CH_3–CH(OH)–CH_2(OH) + 6H^+ + 2MnO_2 + 8OH^–$

Учтём, что в продуктах реакции $6$ ионов $H^+$+ и $8$ ионов $OH^–$ образуют $6$ молекул $H_2O$ и $2$ иона $OH^–$. Поэтому в правой части уравнения появляется дополнительная запись: $6H_2O + 2OH^–$.

После приведения подобных членов в обеих частях уравнения получим:

$3CH_3–CH=CH_2 + 2MnO_4^- + 4H_2O \rightarrow 3CH_3–CH(OH)–CH_2(OH) + 2MnO_2 + 2OH^–$

9. Составим полное уравнение реакции, для чего в левую и правую части уравнения вводим недостающие катионы калия:

$3CH_3–CH=CH_2 + 2KMnO_4 + 4H_2O \rightarrow 3CH_3–CH(OH)–CH_2(OH) + 2MnO_2 \downarrow + 2KOH$

10. Проверим правильность расстановки коэффициентов по числу атомов кислорода: в левой части — $12$, в правой части — $12$. Следовательно, коэффициенты расставлены верно.

Обратим также внимание на то, что нейтральной среда в данном процессе считается условно, поскольку в результате реакции происходит образование гидроксида калия, создающего щелочную среду. С учетом этого можно несколько иначе записать полуреакцию окисления пропена, а именно: сравнивая левую и правую части схемы полуреакции:

$CH_3–CH=CH_2 \rightarrow CH_3–CH(OH)–CH_2(OH)$,

делаем вывод, что молекула пропена присоединила $2$ гидроксид-иона $OH^–$. Поэтому можно записать:

$CH_3–CH=CH_2 + 2OH^– \rightarrow CH_3–CH(OH)–CH_2(OH)$,

Суммарный заряд частиц в левой части схемы равен $2 \cdot (–1) = –2$. Правая часть схемы содержит только незаряженные частицы. Следовательно, молекула пропена при окислении отдаёт $2$ электрона:

$CH_3–CH=CH_2 + 2OH^– – 2 \bar{e} \rightarrow CH_3–CH(OH)–CH_2(OH)$

Далее суммируем уравнения полуреакций с учетом коэффициентов:

$CH_3–CH=CH_2 + 2OH^– – 2 \bar{e} \rightarrow CH_3–CH(OH)–CH_2(OH) |3|$

$MnO_4^– + 2H_2O + 3 \bar{e} \rightarrow MnO_2 + 4OH^– |2|$

$3CH_3–CH=CH_2 + 6OH^– + 2MnO_4^– + 4H_2O \rightarrow 3CH_3–CH(OH)–CH_2(OH) + 2MnO_2 + 8OH^–$

После приведения подобных членов в обеих частях уравнения получим:

$3CH_3–CH=CH_2 + 2MnO_4^- + 4H_2O \rightarrow 3CH_3–CH(OH)–CH_2(OH) + 2MnO_2 + 2OH^–$

11. Составим полное уравнение реакции, для чего в левую и правую части уравнения вводим недостающие катионы калия:

$3CH_3–CH=CH_2 + 2KMnO_4 + 4H_2O \rightarrow 3CH_3–CH(OH)–CH_2(OH) + 2MnO_2 + 2KOH$

Совершенно очевидно, что мы приходим к одному и тому же результату.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] **Пример 7.** Приведем ещё один пример расстановки коэффициентов методом полуреакций, например в реакции окисления пентена–$2$. Но в качестве окислителя будем использовать не перманганат калия, а бихромат калия $K_2Cr_2O_7$ в кислой среде.

1. Составим схему полуреакции окисления:

$CH_3–CH=CH–CH_2–CH_3 \rightarrow CH_3–COOH + CH_3–CH_2–COOH$

2. Уравняем число атомов кислорода в левой и правой части схемы полуреакции окисления с учётом среды. Источником кислорода в кислой среде являются молекулы воды. Образовавшиеся в результате окисления одной молекулы пентена–$2$ одна молекула уксусной кислоты и одна молекула пропионовой кислоты содержат $4$ атома кислорода. Следовательно, в полуреакции окисления примут участие $4$ молекулы $H_2O$:

$CH_3–CH=CH–CH_2–CH_3 + 4H_2O \rightarrow CH_3–COOH + CH_3–CH_2–COOH$

3. Уравняем число атомов водорода в левой и правой части схемы полуреакции окисления. В левой части полуреакции содержится $18$ атомов водорода, в правой — $10$; следовательно, в результате процесса окисления высвобождается $18 – 10 = 8$ ионов $H^+$:

$CH_3–CH=CH–CH_2–CH_3 + 4H_2O \rightarrow CH_3–COOH + CH_3–CH_2–COOH + 8H^+$

4. Сравним суммарный заряд частиц в левой и правой части схемы полуреакции окисления. Левая часть схемы содержит только незаряженные частицы, суммарный заряд в правой части равен $+8$. Следовательно, молекула пентена–$2$ при окислении отдает $8$ электронов:

$CH_3–CH=CH–CH_2–CH_3 + 4H_2O – 8 \bar{e} \rightarrow CH_3–COOH + CH_3–CH_2–COOH + 8H^+$

5. Составим схему полуреакции восстановления:

$Cr_2O_7^{2–} \rightarrow 2Cr^{3+}$

6. Уравняем число атомов кислорода в левой и правой части схемы полуреакции восстановления с учётом среды. Процесс протекает в кислой среде, при этом избыток кислорода связывается ионами $H^+$: для связывания $7$ атомов кислорода необходимо $14$ ионов $H^+$, в результате чего образуется $7$ молекул $H_2O$:

$Cr_2O_7^{2–} + 14H^+ \rightarrow 2Cr^{3+} + 7H_2O$

7. Сравним суммарный заряд частиц в левой и правой части схемы полуреакции восстановления. Вычислим суммарный заряд частиц в левой части схемы: $–2 + 14 \cdot (+1) = +12$. В правой части схемы суммарный заряд равен $2 \cdot (+3) = +6$. Следовательно, для восстановления одного иона $Cr_2O_7^{2-}$ необходимо $6$ электронов:

$Cr_2O_7^{2–} + 14H^+ + 6 \bar{e} \rightarrow 2Cr^{3+} + 7H_2O$

8. Суммируем уравнения полуреакций с учётом коэффициентов. Для этого находим наименьшее общее кратное числа отданных ($–8 \bar{e}$) и принятых ($+6 \bar{e}$) электронов, которое равно $24$. Значит, первую полуреакцию надо умножить на $3$, а вторую — на $4$:

$CH_3–CH=CH–CH_2–CH_3 + 4H_2O – 8 \bar{e} \rightarrow CH_3–COOH + CH_3–CH_2–COOH + 8H^+ |3|$

$Cr_2O_7^{2–} + 14H^+ + 6 \bar{e} \rightarrow 2Cr^{3+} + 7H_2O |4|$

$3CH_3–CH=CH–CH_2–CH_3 + 12H_2O + 4Cr_2O_7^{2–} + 56H^+ \rightarrow 3CH_3–COOH + 3CH_3–CH_2–COOH + 24H^+ 8Cr^{3+} + 28H_2O|3|$

Приводим подобные члены в обеих частях уравнения и получаем:

$3CH_3–CH=CH–CH_2–CH_3 + 4Cr_2O_7^{2-} + 32H^+ \rightarrow 3CH_3–COOH + 3CH_3–CH_2–COOH + 8Cr^{3+} + 16H_2O$

9. Составим полное уравнение реакции, для чего в левую и правую части уравнения вводим недостающие катионы калия и сульфат-анионы:

$3CH_3–CH=CH–CH_2–CH_3 + 4K_2Cr_2O_7 + 16H_2SO_4 \rightarrow 3CH_3–COOH + 3CH_3–CH_2–COOH + 4Cr_2(SO_4)_3 + 16H_2O$

10. Проверим правильность расстановки коэффициентов по числу атомов кислорода: в левой части — $92$, в правой части — $92$. Следовательно, коэффициенты расставлены верно.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] **Пример 8.** Расставим коэффициенты методом полуреакций в реакции окисления гомолога бензола — пропилбензола — водным раствором перманганата калия при нагревании.

1. Составим схему полуреакции окисления. Учтём, что в результате реакции образуется соль бензойной кислоты, которая, в отличие от бензойной кислоты, является сильным электролитом. Поэтому в правой части схемы вместо формулы соли $C_6H_5–COOK$ следует записать формулу бензоат-иона $C_6H_5–COO–$. Два других атома углерода в боковой цепи окисляются до двух уксусной кислоты, которая в этих условиях образует ацетат калия $CH_3COOK$. Ацетат калия, как и бензоат калия, является сильным электролитом, поэтому запишем в правой части схемы вместо формулы соли формулу ацетат-иона $CH_3COO^–$:

$C_6H_5–CH_2–CH_2–CH_3 \rightarrow C_6H_5–COO^– + CH_3–COO^–$

2. Уравняем число атомов кислорода в левой и правой части схемы полуреакции окисления с учётом среды. Источником кислорода в нейтральной среде, как и в кислой, являются молекулы воды. В продуктах окисления пропилбензола содержится $2 + 2 = 4$ атома кислорода. Следовательно, в полуреакции окисления примут участие $4$ молекулы $H_2O$:

$C_6H_5–CH_2–CH_2–CH_3 + 4H_2O \rightarrow C_6H_5–COO^– + CH_3–COO^–$

3. Уравняем число атомов водорода в левой и правой части схемы полуреакции окисления. В левой части полуреакции содержится на $12$ атомов водорода больше, чем в правой; следовательно, в результате процесса окисления высвобождается $12$ ионов $H^+$:

$C_6H_5–CH_2–CH_2–CH_3 + 4H_2O \rightarrow C_6H_5–COO^– + CH_3–COO^– + 12H^+$

4. Сравним суммарный заряд частиц в левой и правой части схемы полуреакции окисления. Левая часть схемы содержит только незаряженные частицы, суммарный заряд в правой части равен $–1 + (–1) + 12 = +10$. Следовательно, молекула пропилбензола при окислении отдает $10$ электронов:

$C_6H_5–CH_2–CH_2–CH_3 + 4H_2O – 10 \bar{e} \rightarrow C_6H_5–COO^– + CH_3–COO^– + 12H^+$

5. Составим схему полуреакции восстановления:

$MnO_4^– \rightarrow MnO_2$

6. Уравняем число атомов кислорода в левой и правой части схемы полуреакции восстановления с учётом среды. Процесс протекает в нейтральной среде, при этом избыток кислорода связывается молекулами воды $H_2O$ с образованием гидроксид-ионов $OH^–$. Прибавим молекулы $H_2O$ в левую часть схемы, а в правую — гидроксид-ионы $OH^–$. Затем уравняем число атомов кислорода и водорода в обеих частях схемы полуреакции. Для этого поставим перед формулой $H_2O$ коэффициент $2$, а перед формулой гидроксид-ионов $OH^–$ коэффициент $4$:

$MnO_4^– + 2H_2O \rightarrow MnO_2 + 4OH^–$

7. Сравним суммарный заряд частиц в левой и правой части схемы полуреакции восстановления. Суммарный заряд частиц в левой части схемы равен $–1$, в правой части суммарный заряд составляет $4 ∙ (–1) = –4$. Следовательно, для восстановления одного иона $MnO_4^{–}$ необходимо $3$ электрона:

$MnO_4^– + 2H_2O + 3 \bar{e} \rightarrow MnO_2 + 4OH^–$

8. Суммируем уравнения полуреакций с учётом коэффициентов. Для этого находим наименьшее общее кратное числа отданных ($–18 \bar{e}$) и принятых ($+3 \bar{e}$) электронов, которое равно $18$. Значит, первую полуреакцию надо умножить на $1$, а вторую — на $6$:

$C_6H_5–CH_2–CH_2–CH_3 + 4H_2O – 10 \bar{e} \rightarrow C_6H_5–COO^– + CH_3–COO^– + 12H^+ |3|$

$MnO_4^– + 2H_2O + 3 \bar{e} \rightarrow MnO_2 + 4OH^– |10|$

$3C_6H_5–CH_2–CH_2–CH_3 + 12H_2O + 10MnO_4^– + 20H_2O \rightarrow 3C_6H_5–COO^– + 3CH_3–COO^– + 36H^+ + 10MnO_2 + 40OH^–$

Учтём, что в продуктах реакции $36$ ионов $H^+$ и $40$ ионов $OH^–$ образуют $36$ молекул $H_2O$ и $4$ иона $OH^–$. Поэтому в правой части уравнения появляется дополнительная запись: $36H_2O + 4OH^–$.

После приведения подобных членов в обеих частях уравнения получим:

$3C_6H_5–CH_2–CH_2–CH_3 + 10MnO_4^– \rightarrow 3C_6H_5–COO^– + 3CH_3–COO^– + 10MnO_2 + 4OH^– + 4H_2O$

9. Составим полное уравнение реакции, для чего в левую и правую части уравнения вводим недостающие катионы калия:

$3C_6H_5–CH_2–CH_2–CH_3 + 10KMnO_4 \rightarrow 3C_6H_5–COOK + 3CH_3–COOK + 10MnO_2 + 4KOH + 4H_2O$

10. Проверим правильность расстановки коэффициентов по числу атомов кислорода: в левой части — $40$, в правой части — $40$. Следовательно, коэффициенты расставлены верно.
