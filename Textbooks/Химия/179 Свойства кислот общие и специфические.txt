Химические свойства кислот можно разделить на две группы: общие для всех кислот, связанные с наличием в их растворах ионов водорода $H^+$, и специфические, т. е. характерные для конкретных кислот.

## [рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8698/c5bf3e653a429f6e.png] **Общие свойства кислот**

Кислоты можно распознавать с помощью индикаторов.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7481/45b37fb3ae13f4e1.png] {**Окраска некоторых индикаторов в нейтральной и кислотной среде**}

| Лакмус | {**Фиолетовая**} | {**Красная**} |

| Фенолфталеин | **Бесцветная** | **Бесцветная** (фенолфталеин нельзя использовать для определения кислотной среды) |

К общим свойствам кислот относятся:

1. Взаимодействие с металлами, расположенными в ряду напряжений до водорода (активные металлы и металлы средней активности)

**Металл (до $H$) + кислота = соль + $H_2$**

Например:

$Zn + H_2SO_4 = ZnSO_4 + H_2 \uparrow$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/150559/f5d7d88df6221528.png]

**Рис. 1. Ряд напряжений (ряд активности) металлов.**

2. Взаимодействие с основными и амфотерными оксидами

**Основный (амфотерный) оксид + кислота = соль + $H_2O$**

Например:

$2HCl + CaO = CaCl_2 + H_2O$

$2HNO_3 + ZnO = Zn(NO_3)_2 + H_2O$

3. Взаимодействие с основаниями и амфотерными гидроксидами

**Основание (амфотерный гидроксид) + кислота = соль + $H_2O$**

Например:

$H_2SO_4 + 2NaOH = Na_2SO_4 + 2H_2O$

$3HCl + Al(OH)_3 = AlCl_3 + 3H_2O$

4. Взаимодействие с солями, если образуется малорастворимое, летучее или малодиссоциирующее вещество

**Соль + кислота = другая соль + другая кислота**

Например:

$H_2SO_4 + BaCl_2 = BaSO_4 \downarrow + 2HCl$

$2HCl + Na_2CO_3 = 2NaCl + H_2O + CO_2 \uparrow$

5. Некоторые кислоты разлагаются:

а) без нагревания

$H_2CO_3 = H_2O + CO_2 \uparrow$

$H_2SO_3 = H_2O + SO_2 \uparrow$

б) при нагревании

$H_2SiO_3 = H_2O + SiO_2$

$4HNO_3 = 4NO_2 \uparrow + O_2 \uparrow + 2H_2O$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8748/4b65d2672cef7080.png] {**Коротко о главном**}

Общие химические свойства кислот обусловлены наличием катиона водорода в их составе. К общим свойствам кислот относятся:

- изменение окраски индикаторов;

- взаимодействие с металлами, стоящими в электрохимическом ряду напряжений до водорода, с выделением водорода;

- взаимодействие с основными и амфотерными оксидами, основаниями и амфотерными гидроксидами;

- взаимодействие с солями, если в результате реакции образуются осадок, газ или малодиссоциирующее соединение.

Специфические свойства кислот обусловлены особенностями анионов кислотного остатка.

## [рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8698/c5bf3e653a429f6e.png] **Специфические свойства кислот**

Бескислородные галогеноводородные кислоты ($HCl, HBr, HI$), а также сероводородная кислота $H_2S$ в водном растворе проявляют восстановительные свойства за счёт галогенид-ионов:

$2KMnO_4 + 16HCl = 5Cl_2 + 2KCl + 2MnCl_2 + 8H_2O$

$H_2S + Br_2 = S + 2HBr$

Кислородсодержащие кислоты, в которых центральный атом, входящий в состав аниона, находится в промежуточной степени окисления, могут проявлять как восстановительные, так и окислительные свойства, например:

$H_2SO_3 + Cl_2 + H_2O = H_2SO_4 + 2HCl$
Восстановитель

$H_2SO_3 + 2H_2S = 3S + 3H_2O$
Окислитель

Многие кислородсодержащие кислоты, в которых центральный атом имеет максимальную степень окисления ($N^{+5}, S^{+6}, Cr^{+6}$), проявляют свойства сильных окислителей:

$3P + 5HNO_3 + 2H_2O = 3H_3PO_4 + 5NO$

$Cu + 2H_2SO_4 (конц.) = CuSO_4 + SO_2 + 2H_2O$
