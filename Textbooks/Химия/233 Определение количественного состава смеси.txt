Определение количественного состава смесей нескольких веществ с похожими свойствами представляет собой математическую задачу, наиболее простым способом решения которой, как правило, является составление и решение системы уравнений.




[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7478/8aa81b40d50ef291.png] {**Алгоритм решения задач на определение количественного состава смеси**}


1. Обозначить количество веществ через $x$, $y$, $z$.


2. Составить уравнения, связывающие эти переменные с численными данными, приведёнными в условии задачи, причём число уравнений обычно должно равняться числу переменных.


3. Решить систему уравнений, то есть найти количество каждого из веществ смеси.






[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] {**Определение состава смеси без протекания химической реакции**}




Самым простым вариантом таких задач являются задания на нахождение веществ в смеси, когда не протекает химическая реакция. Рассмотрим пример решения такой задачи.




{**Задача 1**}




$19$ г смеси метана и этана при нормальных условиях занимают объём $16,8$ л. Определить объёмную долю метана в смеси.








**Решение**




1. По условию задачи:


$m_{CH_4} + m_{C_2H_6} = m_{смеси}$ и $V_{CH_4} + V_{C_2H_6} = V_{смеси}$


2. Пусть в смеси


$n_{CH_4} = x$ моль, $n_{C_2H_6} = y$ моль, тогда $m_{CH_4} = 16x, а m_{C_2H_6} = 30y$


Следовательно,


$16x + 30y = 19$


Тогда


$V_{CH_4} = 22,4x$, а $V_{C_2H_6} = 22,4y$


Следовательно,


$22,4x + 22,4y = 16,83$


Составим систему двух уравнений с двумя неизвестными:


$\begin{equation*} \begin{cases} 16x + 30y = 19 \\ 22,4x + 22,4y = 16,83 \end{cases}\end{equation*}$


Решая систему, получаем:


$x = 0,25$, $y = 0,54$


Находим объём метана и его объёмную долю в смеси:


$V_{CH_4} = 22,4 \cdot 0,25 = 5,6$ л


$\phi_{CH_4} = \dfrac{5,616,8} = 0,33$, или $33$%














[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] {**Определение состава смеси продуктов химической реакции**}




Наиболее типичный пример таких задач — это определение состава смеси продуктов, образующихся в результате сжигания. Рассмотрим пример решения такой задачи.




{**Задача 2**}




Смесь кислорода с $5$% по объёму метана сожгли в контактном аппарате. Определите состав газовой смеси на выходе.




**Решение**




1. Составляем уравнение реакции горения метана:




$CH_4 + 2O_2 = CO_2 + 2H_2O$




2. Пусть объём $V$ исходной смеси $100$ л, тогда она имела исходных состав: $5$ л $CH_4$ и $95$ л кислорода. Таким образом, при сгорании $5$ л метана израсходуется $10$ л кислорода и образуется $5$ л углекислого газа.


3. Определяем состав образовавшейся смеси.


$V_{CH_4} = 0$ л; $V_{O_2} = 95 – 10 = 85$ л; $V_{CO_2} = 5$ л.


Общий объём смеси равен $90$ л.


Тогда в объёмных долях:


$\phi_{O_2} = \dfrac{8590} = 0,94$, или $94$ %,


$\phi_{CO_2} = \dfrac{590} = 0,06$, или $6$ %.

{**Задача 3**}




При полном сжигании $258$ г смеси этилового спирта и уксусной кислоты образовалось $234$ г воды. Найдите состав исходной смеси (в массовых долях).




Решение




1. Составим уравнения протекающих реакций:




$C_2H_5OH + 3O_2 = 2CO_2 + 3H_2O$






$CH_3COOH + 2O_2 = 2CO_2 + 2H_2O$






2. Пусть




$n_{C_2H_5OH} = x$, а $n_{CH_3COOH} = y$


Тогда


$m_{C_2H_5OH} = 46x$, $m_{CH_3COOH} = 60y$, а $m_{смеси} = 46x + 60y = 258$


3. Количество образовавшейся воды:


$n_{H_2O} = \dfrac{23418} = 13$ моль


Тогда по уравнению 1


$n_{H_2O} = 3x$,


по уравнению 2


$n_{H_2O} = 2y$,


$n_{общее H_2O} = 3x + 2y = 13$


Составляем и решаем систему уравнений:


$\begin{equation*} \begin{cases} 46x + 60y = 258 \\ 3x + 2y = 13 \end{cases}\end{equation*}$


Находим:


$x = 3$ моль $C_2H_5OH$,


$y = 2$ моль $CH_3COOH$


4. Определяем состав смеси:


$m_{C_2H_5OH} = 3 \cdot 46 = 138$ г;


$\omega_{C_2H_5OH} = \dfrac{138258} = 0,535$, или $53,5$ %;


$m_{CH_3COOH} = 2 \cdot 60 = 120$ г;


$\omega_{CH_3COOH} = \dfrac{120258} = 0,465$, или $46,5$%.
