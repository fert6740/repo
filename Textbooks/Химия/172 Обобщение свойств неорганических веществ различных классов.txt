Кратко обобщим общие типичные свойства неорганических веществ различных классов.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/89477/d13d4525ab702f54.png] {**Общие химические свойства основных оксидов**}

1. Основный оксид + кислота → соль + вода

$MgO + 2HNO_3 = Mg(NO_3)_2 + H_2O$

$MgO + 2H^+ + 2NO_3^- = Mg^{2+} + 2NO_3^- + H_2O$

$MgO + 2H^+ = Mg^{2+} + H_2O$

2. Основный оксид + кислотный оксид → соль

$CaO + CO_2 = CaCO_3$

3. Основный оксид активного металла + вода → щёлочь

$CaO + H_2O = Ca(OH)_2$

$FeO + H_2O ≠$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/89478/cd5199be3690eceb.png] {**Общие химические свойства кислотных оксидов**}

1. Кислотный оксид + щёлочь → соль + вода

$CO_2 + 2NaOH = Na_2CO_3 + H_2O$

$CO_2 + 2Na^+ + 2OH^− = 2Na^+ + CO_3^{2-} + H_2O$

$CO_2 + 2OH^− = CO_3^{2-} + H_2O$

2. Кислотный оксид + основный оксид → соль

$CO_2 + CaO= CaCO_3$

3. Кислотный оксид + вода → кислота

$SO_3 + H_2O = H_2SO_4$

Исключение: $SiO_2 + H_2O ≠$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/89479/f162e6f955ef8a1f.png] {**Общие химические свойства амфотерных оксидов**}

1. Амфотерный оксид + кислота → соль + вода

$ZnO + 2HCl = ZnCl_2 + H_2O$

$ZnO + 2H^+ + 2Cl^- = Zn^{2+} +2Cl^- + H_2O$

$ZnO + 2H^+ = Zn^{2+} + H_2O$

2. Амфотерный оксид + щёлочь $\xrightarrow{сплавление}$ соль + вода

$ZnO + 2NaOH \xrightarrow{сплавление} Na_2ZnO_2 + H_2O$

Амфотерный оксид + щёлочь(р-р) → комплексная соль

$ZnO + 2NaOH(р-р) + H_2O = Na_2[Zn(OH)_4]$

$ZnO + 2Na^+ + 2OH^- + H_2O = 2Na^+ +[Zn(OH)_4]^{2-}$

$ZnO + 2OH^- + H_2O = [Zn(OH)_4]^{2-}$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/89480/c84df47c15add860.png] {**Общие химические свойства оснований**}

1. Основание + кислота → соль + вода

$NaOH + HCl = NaCl + H_2O$

$Na^+ + OH^− + H^+ +Cl^- = Na^+ + Cl^- + H_2O$

$H^+ + OH^− = H_2O$

$Mg(OH) + 2HCl = 2MgCl + 2H_2O$

$Mg(OH)_2 + 2H^+ +2 Cl^- = Mg^{2+} + 2Cl^- + 2H_2O$

$Mg(OH)_2 + 2H^+ = Mg^{2+} + 2H_2O$

2. Щёлочь + кислотный оксид → соль + вода

$2KOH + SO_2 = K_2SO_3 + H_2O$

$2K^+ + 2OH^− + SO_2 = 2K^+ + SO_3^{2-} + H_2O$

$SO_2 + 2OH^− = SO_3^{2-} + H_2O$

3. Щёлочь + соль1 → новое основание + соль2, если образуется осадок или газ

$2KOH + FeSO_4 = Fe(OH)_2\downarrow + K_2SO_4$

$2K^+ + 2OH^− + Fe^{2+} + SO_4^{2-} = Fe(OH)_2\downarrow + 2K^+ + SO_4^{2-}$

$Fe^{2+} + 2OH^− = Fe(OH)_2\downarrow$

$KOH + NH_4Cl = NH_3\uparrow + H_2O + KCl$ (при нагревании)

$K^+ + OH^− + NH_4^+ + Cl^- = NH_3\uparrow + H_2O + K^+ + Cl^-$

$NH_4^+ + OH^− = NH_3\uparrow + H_2O$

4. Нерастворимое основание $ \xrightarrow{t}$ оксид металла + вода

$2AgOH = Ag_2O + H_2O$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/89486/c8910c4ac1e10dac.png] {**Общие химические свойства кислот**}

1. Кислота + основание или амфотерный гидроксид → соль + вода

$HCl + NaOH = NaCl + H_2O$

$H^+ + Cl^− + Na^+ + OH^− = Cl^− + Na^+ + H_2O$

$H^+ + OH^− = H_2O$

$2HNO_3 + Fe(OH)_2 = Fe(NO_3)_2 + 2H_2O$

$2H^+ + 2NO_3^- + Fe(OH)_2 = Fe^{2+} + 2NO_3^- + 2H_2O$

$Fe(OH)_2 + 2H^+ = Fe^{2+} + 2H_2O$

$2HNO_3 + Zn(OH)_2 = Zn(NO_3)_2 + 2H_2O$

$2H^+ + 2NO_3^- + Zn(OH)_2 = Zn^{2+} + 2NO_3^- + 2H_2O$

$Zn(OH)_2 + 2H^+ = Zn^{2+} + 2H_2O$

2. Кислота + основный или амфотерный оксид → соль + вода

$H_2SO_4 + MgO = MgSO_4 + H_2O$

$2H^+ + SO_4^{2-} + MgO = Mg^{2+} + SO_4^{2-} + H_2O$

$MgO + 2H^+ = Mg^{2+} + H_2O$

$H_2SO_4 + ZnO = ZnSO_4 + H_2O$

$2H^+ + SO_4^{2-} + ZnO = Zn^{2+} + SO_4^{2-} + H_2O$

$ZnO + 2H^+ = Mg^{2+} + H_2O$

3. Кислота1 + соль1 → кислота2 + соль2, если образуется осадок или выделяется газ

$H_2SO_4 + BaCl_2 = BaSO_4\downarrow + 2HCl$

$2H^+ + SO_4^{2-} + Ba^{2+} + 2Cl^− = BaSO_4\downarrow + 2H^+ + 2Cl^−$

$Ba^{2+} + SO_4^{2-} = BaSO_4\downarrow$

$2HCl+ Na_2CO_3 = 2NaCl + CO_2\uparrow + H_2O$

$2H^+ + 2Cl^- + 2Na^+ + CO_3^{2-} = 2Na^+ + 2Cl^- + CO_2\uparrow + H_2O$

$2H^+ + CO_3^{2-} = CO_2\uparrow + H_2O$

4. Кислота + металл, стоящий в электрохимическом ряду напряжений до водорода → соль + водород (кроме $HNO_3$ любой концентрации и концентрированной $H_2SO_4$)

$Zn + 2HCl = ZnCl_2 + H_2$

$Zn + 2H^+ + 2Cl^− = Zn^{2+} + 2Cl^− + H_2$

$Zn + 2H^+ = Zn^{2+} + H_2$

$Cu + HCl ≠$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/89489/b5f9a0a03544fd15.png] {**Общие химические свойства амфотерных гидроксидов**}

1. Амфотерный гидроксид + кислота → соль + вода (основные свойства)

$Zn(OH)_2 + 2HCl = ZnCl_2 + 2H_2O$

$Zn(OH)_2 + 2H^+ + 2Cl^− = Zn^{2+} + 2Cl^− + 2H_2O$

$Zn(OH)_2 + 2H^+ = Zn^{2+} + 2H_2O$

2. Амфотерный гидроксид + щёлочь $\xrightarrow{сплавление}$ соль + вода (кислотные свойства)

$Zn(OH)_2 + 2NaOH \xrightarrow{сплавление} Na_2ZnO_2 + 2H_2O$

Амфотерный оксид + щёлочь(р-р) → комплексная соль

$Zn(OH)_2 + 2NaOH(р-р) = Na_2[Zn(OH)_4]$

$Zn(OH)_2 + 2Na^+ + 2OH^- = 2Na^+ +[Zn(OH)_4]^{2-}$

$Zn(OH)_2 + 2OH^- = [Zn(OH)_4]^{2-}$

3. Амфотерный гидроксид $ \xrightarrow{t}$ оксид металла + вода

$Zn(OH)_2 = ZnO + H_2O$

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/89490/a270007822982a93.png] {**Общие химические свойства солей**}

1. Соль1 + кислота1 → соль2 + кислота2, если образуется осадок или газ

$AgNO_3 + HCl = AgCl\downarrow + HNO_3$

$Ag^+ + NO_3^- + H^+ + Cl− = AgCl\downarrow + H^+ + NO_3^−$

$Ag^+ + Cl^- = AgCl\downarrow$

$Na_2CO_3 + 2HNO_3 = 2NaNO_3 + CO_2 \uparrow+ H_2O$

$2Na^+ + CO_3^{2-} + 2H^+ + 2NO_3^- = 2Na^+ + 2NO_3^- + CO_2\uparrow + H_2O$

$2H^+ + CO_3^{2-} = CO_2\uparrow + H_2O$

$NaNO_3(р-р) + H_2SO_4(р-р) ≠$

2. Соль1 + щёлочь → соль2 + новое основание, если образуется осадок или газ

$FeSO_4 + 2NaOH = Fe(OH)_2\downarrow + Na_2SO_4$

$Fe^{2+} + SO_4^{2-} + 2Na^+ + 2OH^− = Fe(OH)_3\downarrow + 2Na^+ + SO_4^{2-}$

$Fe^{2+} + 2OH^− = Fe(OH)_2\downarrow$

$NH_4Cl + KOH = NH_3\uparrow + H_2O + KCl$ (при нагревании)

$NH_4^+ + Cl^- + K^+ + OH^− = NH_3\uparrow + H_2O + K^+ + Cl^-$

$NH_4^+ + OH− = NH_3\uparrow + H_2O$

$BaCl_2 + KOH ≠$

3. Соль1 + соль2 → соль3 + соль4, если образуется осадок

$BaCl_2 + Na_2SO_4 = BaSO_4\downarrow + 2NaCl$

$Ba^{2+} + 2Cl^− + 2Na^+ + SO_4^{2-} = BaSO_4\downarrow + 2Na^+ + 2Cl^−$

$Ba^{2+} + SO_4^{2-} = BaSO_4\downarrow$

4. Соль1 + металл1 → соль2 + металл2, если металл1 в свободном состоянии более активен, чем металл в составе соли1

$CuSO_4 + Fe = FeSO_4 + Cu$

$Cu^{2+} + SO_4^{2-} + Fe = Fe^{2+} + SO_4^{2-} + Cu$

$Cu^{2+} + Fe = Cu + Fe^{2+}$

$FeSO_4 + Cu ≠$
