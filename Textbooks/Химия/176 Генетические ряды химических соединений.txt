## Понятие генетической связи

Вещества одного класса в результате химических превращений могут превращаться в вещества другого класса, но при этом содержать один и тот же химический элемент, например:

простое вещество $\rightarrow$ оксид $\rightarrow$ кислота $\rightarrow$ соль;

простое вещество $\rightarrow$ оксид $\rightarrow$ щелочь $\rightarrow$ соль.

{**Генетическая связь**}

связь между веществами различных классов, основанная на их взаимопревращениях и отражающая единство их происхождения, т. е. генезис веществ.

Различают **генетическую связь металлов** и **генетическую связь неметаллов**. Для отображения связи между соединениями одного элемента, строят генетические ряды:

**Рис. 1.** Генетические ряды металлов и неметаллов

Однако предложенная схема отражает не все, а только наиболее типичные взаимосвязи между различными классами неорганических веществ, так как не все вещества можно получить прямым методом.

Так, кислород непосредственно не взаимодействует с серебром, золотом, платиной, галогенами. Оксиды этих элементов получают косвенным путём. Например, оксид хлора($VII$) $Cl_2O_7$ получают действием $P_2O_5$ на хлорную кислоту:

$2HClO_4 + P_2O_5 \rightarrow Cl_2O_7 + 2HPO_3$

Взаимодействие азота с кислородом приводит к образованию несолеобразующего оксида азота($II$) $NO$, остальные оксиды азота получают другими методами. Например, оксид азота($V$) $N_2O_5$ получают способом, аналогичным способу получения $Cl_2O_7$, т. е. путем действия $P_2O_5$ на $HNO_3$:

$HNO_3 + P_2O_5 \rightarrow N_2O_5 + HPO_3$

Следует учесть также, что не все основные и кислотные оксиды взаимодействуют с водой с образованием соответствующих гидроксидов (оснований или кислот). Так, чтобы получить гидроксиды неактивных и малоактивных металлов, оксид сначала следует перевести в соль путём его взаимодействия с кислотой, а затем на полученную соль подействовать раствором щелочи. Например, для получения гидроксида железа($II$) можно сначала на оксид железа($II$) подействовать соляной (но не азотной и не концентрированной серной!) кислотой, а затем добавить к полученной соли гидроксид калия:

$FeO + 2HCl \rightarrow FeCl_2 + H_2O$

$FeCl_2 + 2KOH \rightarrow Fe(OH)_2 \downarrow + 2KCl$

Аналогично, слабую нерастворимую кремниевую кислоту нельзя получить при взаимодействии $SiO_2$ с водой. Сначала оксид кремния($IV$) обрабатывают щелочью, получая растворимую соль — силикат, на который затем действуют кислотой:

$SiO_2 + 2NaOH \rightarrow Na_2SiO_3 + H_2O$

$Na_2SiO_3 + H_2SO_4 \rightarrow H_2SiO_3 \downarrow + Na_2SO_4$

Проиллюстрируем генетическую связь между классами соединений на примерах генетических рядов металлов и неметаллов. При составлении уравнений реакций будем учитывать как общие, так и специфические свойства и способы получения веществ различных классов.

## Генетическая связь (генетический ряд) металлов

**а)** металл $\rightarrow$ основный оксид $\rightarrow$ **растворимое основание (щёлочь)** $\rightarrow$ соль

В качестве примера рассмотрим цепочку для кальция:

$Ca \rightarrow CaO \rightarrow Ca(OH)_2 \rightarrow Ca_3(PO_4)_2$

Оксид кальция можно получить путём взаимодействия кальция с кислородом:

$2Ca + O_2 \rightarrow 2CaO$

Оксиды щёлочноземельных металлов, к которым принадлежит кальций, взаимодействуют с водой с образованием растворимых оснований:

$CaO + H_2O \rightarrow Ca(OH)_2$

Соль — фосфат кальция — можно получить при взаимодействии гидроксида кальция с ортофосфорной кислотой:

$3Ca(OH)_2 + 2H_3PO_4 \rightarrow Ca_3(PO_4)_2 \downarrow + 6H_2O$

**б)** металл $\rightarrow$ основный (или амфотерный) оксид $\rightarrow$ соль $\rightarrow$ **нерастворимый гидроксид металла** $\rightarrow$ основный (или амфотерный) оксид $\rightarrow$ металл

Например, ряд для меди:

$Cu \rightarrow CuO \rightarrow CuSO_4 \rightarrow Cu(OH)_2 \rightarrow CuO \rightarrow Cu$

Оксид меди($II$) - амфотерный оксид с преобладанием основных свойств. Оксид меди($II$) можно получить путём взаимодействия меди с кислородом:

$2Cu + O_2 \xrightarrow{t} 2CuO$

Чтобы получить нерастворимый гидроксид меди($II$), надо сначала на оксид меди($II$) подействовать кислотой и получить растворимую соль меди($II$):

$CuO + H_2SO_4 \rightarrow CuSO_4 + H_2O$

Нерастворимый гидроксид $Cu(OH)_2$ можно получить из растворимой соли $CuSO_4$ действием на неё раствором щёлочи:

$CuSO_4 + 2NaOH \rightarrow Cu(OH)_2 \downarrow + Na_2SO_4$

Нерастворимые гидроксиды металлов разлагаются при нагревании с образованием оксида металла и воды:

$Cu(OH)_2 \xrightarrow{t} CuO + H_2O$

Восстановить медь из её оксида можно с помощью водорода, пропуская его над нагретым оксидом:

$CuO + H_2 \xrightarrow{t} Cu + H_2O$

## Генетическая связь (генетический ряд) неметаллов

**а)** неметалл $\rightarrow$ кислотный оксид $\rightarrow$ **растворимая кислота** $\rightarrow$ соль

Пример для фосфора:

$P \rightarrow P_2O_5 \rightarrow H_3PO_4 \rightarrow K_3PO_4$

Оксид фосфора($V$) получают, сжигая фосфор в избытке кислорода:

$4P + 5O_2(изб.) \xrightarrow{t} 2P_2O_5$

Кислотные оксиды взаимодействуют с водой с образованием кислот:

$P_2O_5 + 3H_2O \rightarrow 2H_3PO_4$

Соль из кислоты можно получить при её взаимодействии с соответствующим основанием — гидроксидом калия:

$H_3PO_4 + 3KOH \rightarrow K_3PO_4 + 3H_2O$

**б)** неметалл $\rightarrow$ кислотный оксид $\rightarrow$ соль $\rightarrow$ **нерастворимая кислота** $\rightarrow$ кислотный оксид $\rightarrow$ неметалл

Пример для кремния:

$Si \rightarrow SiO_2 \rightarrow K_2SiO_3 \rightarrow H_2SiO_3 \rightarrow SiO_2 \rightarrow Si$

Оксид кремния($IV$) получается при сжигании кремния в кислороде:

$Si + O_2 \xrightarrow{t} SiO_2$

Затем надо получить растворимый силикат, например силикат калия $K_2SiO_3$, для чего можно сплавить оксид кремния($IV$) со щёлочью:

$SiO_2 + 2KOH \xrightarrow{t} K_2SiO_3 + H_2O$

Нерастворимую кремниевую кислоту получают, действуя на полученный силикат калия кислотой, например, азотной:

$K_2SiO_3 + 2HNO_3 \rightarrow H_2SiO_3 \downarrow + 2KNO_3$

Кремниевая кислота разлагается при нагревании:

$H_2SiO_3 \xrightarrow{t} H_2O + SiO_2$

Кремний из оксида кремния($IV$) можно получить путём восстановления, используя в качестве восстановителя, например, уголь:

$SiO_2 + C \xrightarrow{t} Si + CO_2$

Генетическая связь - связь между веществами различных классов, основанная на их взаимопревращениях и отражающая единство их происхождения. Различают генетическую связь металлов и генетическую связь неметаллов.

Для отображения генетической связи между соединениями, содержащими определенный химический элемент, строят генетический ряд. Генетические ряды металлов и неметалов различаются в зависимости от растворимости их гидроксидов.
