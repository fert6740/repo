- Основные расчётные формулы

- Примеры решения задач

Прежде чем провести химическую реакцию, необходимо решить, в каком массовом соотношении смешать исходные вещества, и рассчитать массу продукта, который при этом получится.

Количественными отношениями занимается раздел химии, который называется стехиометрией (от греч. стойхеион — элемент и метрео — измеряю).

Химическое уравнение показывает, какие вещества и в каком количестве реагируют друг с другом, а также какие вещества при этом образуются, сколько каждого из них можно получить.

Вещества вступают в химические реакции в количествах, пропорциональных коэффициентам в уравнении реакции. Это означает, что **отношение количеств реагирующих веществ (в молях) равно отношению соответствующих коэффициентов в уравнении реакции.**

Например, уравнение реакции

$2H_2$ + $O_2$ = $2H_2O$

$2$ моль $1$ моль $2$ моль

показывает, что две молекулы водорода $H_2$ реагируют с одной молекулой кислорода $O_2$ с образованием двух молекул воды $H_2O$.

Рассмотрим ещё один пример. Уравнение:

$H_3PO_4 + 3 NaOH = Na_3PO_4 + 3H_2O$

означает, что при взаимодействии $1$ моля фосфорной кислоты с $3$ молями гидроксида натрия образуется $1$ моль фосфата натрия и $3$ моль воды. Это соотношение можно записать следующим образом:

$n(H_3PO_4) : n(NaOH ) : n(Na_3PO_4) : n(H_2O) = 1 : 3 : 1 : 3 $

Таким образом, количества гидроксида натрия и воды в данной реакции равны:

$n(NaOH)=n(H_2O)$,

а количество фосфорной кислоты в три раза меньше количества гидроксида натрия:

$\dfrac{n(H_3PO_4)n(NaOH)} = \dfrac{13}$.

При решении химических задач используются следующие обозначения физических величин:

$\nu(X)$ — количество вещества $X$, но возможно также обозначение $n(X)$;

$m(X)$ — масса вещества $X$;

$M(X)$ — молярная масса вещества $X$;

$M$(Э) — молярная масса химического элемента Э;

$V(X)$ — объём газа $X$;

$Vр-ра(X)$ — объём раствора вещества $X$;

$V_m$ — молярный объём газа; $V_m = 22,4 \dfrac{лмоль}$ при нормальных условиях;

$\omega(X)$ — массовая доля вещества $X$;

$\omega$(Э) — массовая доля химического элемента в соединении;

$mр-ра(X)$ — масса раствора вещества $X$;

$\eta$ — выход продукта реакции;

$\phi(X)$ — объёмная доля вещества $X$;

$\rho$ — плотность.

Решение расчётных химических задач требует обязательного усвоения следующих расчётных формул:

$\nu = \dfrac{m(X)M(X)}, m(X) = \nu \cdot M(X)$

$\nu(газа) = \dfrac{VгазаV_m} = \dfrac {V(газа)22,4}$ (при нормальных условиях)

$V(газа) = \nu(газа) \cdot V_m = \nu(газа) \cdot 22,4$ (при нормальных условиях)

$\omega(X) = \dfrac{m(X)mр-ра}, m(X) = \omega(X) \cdot m(р-ра), m(р-ра) = \dfrac{m(X)\omega(X)}$

$\omega(примесей) = \dfrac{m(примесей)m(образца)}, m(примесей) = \omega(примесей) \cdot m(образца)$

$m(образца) = \dfrac{m(примесей)\omega(примесей)}$

$\eta = \dfrac{mпрmтеор} = \dfrac{VпрVтеор} = \dfrac{\nuпр\nuтеор}, mпр = \eta \cdot mтеор, Vпр = \eta \cdot Vтеор, \nuпр = \eta \cdot \nuтеор$

$\phi(X) = \dfrac{V(X)V(смеси)}$

$\rho = \dfrac{mV}$

При решении простейших расчётных химических задач по уравнениям реакций можно использовать следующий алгоритм:

1. Составить уравнение химической реакции.

2. Перевести данные задачи (массу, объём) в количество вещества (моль).

3. Найти количества искомых веществ в соответствии с коэффициентами в уравнении реакции.

4. Перевести найденные количества веществ в массу (объём) в соответствии с условием задачи.

5. Оформить ответ.

{**Примеры решения задач по уравнениям реакций с использованием понятий «массовая и объёмная доля выхода продукта реакции»**}

Понятие **практический выход** $\eta$ («эта») используется только для продуктов реакции и означает отклонение массы (объёма) продукта от теоретически возможного. Практические масса, объём или количество вещества показывают, сколько практически получено вещества, а теоретические величины — сколько продукта можно было бы получить в соответствии с расчётами по уравнению реакции.

Практический выход всегда меньше теоретического или равен ему: $\eta_{пр} \le 100$ %.

| Дано. | Решение. |
| $m(KClO_3) = 24,5$ г / $\eta(O_2) = 90$ % / $V(O_2) =$ ? | 1. Составим уравнение реакции: / $2KClO_3 = 2KCl + 3O_2$­ 2. Найдём количество вещества бертолетовой соли: / $\nu = \dfrac{mM}; (KClO_3) = \dfrac{24,5 г122,5 \dfrac{гмоль}} = 0,2$ моль. 3. Найдём теоретический объём кислорода, который мог бы выделиться при разложении $24,5$ г бертолетовой соли: / $V(O_2)теор = \dfrac{32}(KClO_3) = \dfrac{32} \cdot 0,2 моль = 0,3$ моль; / $Vтеор = \etaтеор \cdot V_m; Vтеор(O_2) = 0,3 моль \cdot 22,4 \dfrac{лмоль} = 6,72$ л. 4. Найдём практический объём выделившегося кислорода: / $Vпр = \eta \cdot Vтеор; Vпр(O_2) = 0,9 \cdot 6,72 л = 6,048 л \approx 6,05$ л. / Ответ. $Vпр(O_2) = 6,05$ л. |

{**Примеры решения задач по уравнениям реакций на «избыток-недостаток»**}

Если количества исходных веществ для реакции находятся в строго определённом соотношении в соответствии с коэффициентами в уравнении реакции, то говорят, что они взяты в стехиометрическом соотношении. В этом случае исходные вещества вступают в реакцию полностью, а расчёт массы (объёма) продуктов реакции можно вести по массе (объёму) любого исходного вещества.

Если известны массы нескольких веществ, вступающих в реакцию, то возникает вопрос, по какому веществу определять количество полученных продуктов. Очевидно, что количество продуктов следует определять по тому веществу, которое расходуется полностью, при этом другие реагенты останутся в избытке. Чтобы узнать, какое вещество реагирует полностью, надо найти количества веществ реагентов и сравнить их с соответствующими коэффициентами перед формулами веществ в уравнении реакции.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] Пример 8. К раствору, содержащему $6,3$ г азотной кислоты, добавили раствор, содержащий $6,0$ г гидроксида натрия. Определите массу образовавшейся соли.

| Дано. | Решение. |
| $m(HNO_3) = 6,3$ г / $m(NaOH) = 6$ г / $m(NaNO_3) =$ ? | 1. Составим уравнение реакции: / $HNO_3 + NaOH = NaNO_3 + H_2O$ 2. Найдём количество вещества азотной кислоты и гидроксида натрия: / $\nu = \dfrac{mM}; (HNO_3) = \dfrac{6,3 г63 \dfrac{гмоль}} = 0,1$ моль; / $\nu (NaOH) = \dfrac {6,0 г40 {гмоль}} = 0,15$ моль. 3. Найдём, какое вещество расходуется в реакции полностью: / по уравнению реакции $\dfrac{\nu(HNO_3)\nu(NaOH)} = \dfrac{11}$; / по условию задачи $\dfrac{\nu(HNO3)\nu(NaOH)} = \dfrac{0,10,15} = \dfrac{11,5}$; следовательно, азотная кислота расходуется полностью, а гидроксид натрия взят в избытке. Расчёт следует вести по азотной кислоте. 4. Найдём количество вещества и массу нитрата натрия: / $\nu(NaNO_3) = \nu(HNO_3) = 0,1$ моль; / $m = \nu \cdot M; m(NaNO_3) = 0,1 моль \cdot 85 \dfrac{гмоль} = 8,5$ г. / Ответ. $m(NaNO_3) = 8,5$ г. |

Согласно закону объёмных отношений, объёмы газообразных исходных веществ и газообразных продуктов реакции относятся друг к другу как коэффициенты перед формулами соответствующих веществ.

Использование закона объёмных отношений существенно упрощает расчёты по уравнениям реакций с участием газообразных веществ.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] Пример 10. Какой объём кислорода необходим для сжигания метана объёмом $5$ л? Объёмы газов измерены при одинаковых условиях.

| Дано. | Решение. |
| $V(CH_4) = 5$ л / $V(O_2)$ ? | 1. Составим уравнение реакции: / $CH_4 + 2O_2 = CO_2 + 2H_2O$ 2. По закону объёмных отношений: / $\dfrac{V(CH_4)V(O_2)} = \dfrac{12}$ / Отсюда $V(O_2) = 2V \cdot (CH_4)$ / $V(O_2) = 2 \cdot 5 л = 10$ л / Ответ. $V(O_2) = 10$ л. |

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/6774/50ce87f16fe2c9df.png] Пример 11. Какой объём аммиака можно получить при взаимодействии азота с водородом объёмом $9$ л? Объёмы газов измерены при одинаковых условиях.

| Дано. | Решение. |
| $V(H_2) = 5$ л / $V(NH_3)$ ? | 1. Составим уравнение реакции: / $N_2 + 3H_2 = 2NH_3$ 2. По закону объёмных отношений: / $\dfrac{V(H_2)V(NH_3)} = \dfrac{32}$ / Отсюда $V(NH_3) = \dfrac{23} \cdot V(H_2)$ / $V(NH_3) = \dfrac{23} \cdot 9 л = 6$ л / Ответ. $V(NH_3) = 6$ л. |
