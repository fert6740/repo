**Щёлочи – растворимые в воде основания**, представляют собой твёрдые кристаллические вещества, их растворы мылки на ощупь. Гидроксиды щелочных металлов ($NaOH$, $KOH$) гигроскопичны (поглощают из воздуха водяные пары и расплываются). Щёлочи вызывают сильные химические ожоги при попадании на кожу или в глаза, поэтому их называют также «едкими щелочами».

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7498/ff79eca93bb4e103.png] {**Техника безопасности при работе со щелочами**}

При работе с щелочами требуется жёсткое соблюдение правил безопасности: работать с концентрированными растворами щелочей следует очень аккуратно, обязательно использовать защитные очки. При попадании щёлочи на кожу следует обработать пораженный участок разбавленным раствором слабой кислоты (уксусной или борной), а затем промыть большим количеством воды.

**Нерастворимые в воде основания** выпадают из растворов в виде студенистых аморфных осадков, которые со временем кристаллизуются. Они часто имеют переменный состав. Гидроксиды многих переходных металлов (железа, меди, никеля и др.) окрашены.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7478/8aa81b40d50ef291.png] {**Химические свойства оснований**}

Химические свойства растворимых и нерастворимых оснований различаются, поэтому рассматривать их лучше в сравнении.

| Щёлочи | Нерастворимые основания |
| Изменение окраски индикаторов |
| Фенолфталеин — малиновый; Лакмус – синий; Универсальный индикатор – от синего до фиолетового | Не меняют |
| Взаимодействие с кислотами |
| Реакция нейтрализации: $NaOH + HCl = NaCl + H_2O$ | Растворение нерастворимых гидроксидов: $Fe(OH)_2 + 2HCl = FeCl_2 + 2H_2O$ |
| Взаимодействие с кислотными оксидами |
| $SO_2 + 2KOH(изб.) = K_2SO_3 + H_2O$ $SO_2(изб.) + KOH = KHSO_3$ | — |
| Взаимодействие с амфотерными гидроксидами и оксидами |
| В растворе: $NaOH + Al(OH)_3 = Na[Al(OH)_4]$ $3NaOH + Al(OH)_3 = Na_3[Al(OH)_6]$ При сплавлении: $NaOH + Al(OH)_3 = NaAlO_2 + 2H_2O$ | — |
| Взаимодействие с амфотерными оксидами |
| В растворе: $Al_2O_3 + 2NaOH + 3H_2O = 2Na[Al(OH)_4]$ $Al_2O_3 + 6NaOH + 3H_2O = 2Na_3[Al(OH)_6]$ При сплавлении: $Al_2O_3 + 2NaOH = 2NaAlO_2 + H_2O$ | — |
| Взаимодействие с солями |
| Со средними солями (правило Бертолле): $2NaOH + MgSO_4 = Mg(OH)_2 \downarrow + Na_2SO_4$ С кислыми солями: $NaHCO_3 + NaOH = Na_2CO_3 + H_2O$ | — |
| Разложение при нагревании |
| Из гидроксидов щелочных металлов разлагается только гидроксид лития: $2LiOH = Li_2O + H_2O$ Расплавы всех щелочей, образованных щелочноземельными металлами, также разлагаются на соответствующий оксид и воду: $Ca(OH)_2 = CaO + H_2O$ $Sr(OH)_2 = SrO + H_2O$ $Ba(OH)_2 = BaO + H_2O$ | $2CuOH = Cu_2O + H_2O$ |
| Взаимодействие с неметаллами (галогенами, серой, фосфором, кремнием) |
| $2NaOH_{(конц., \ \ хол.)} + Cl_2 = NaClO + NaCl + H_2O$ $6NaOH_{(конц., \ \ гор.)} + 3Cl_2 = NaClO_3 + 5NaCl + 3H_2O$ $3S + 6KOH_{(конц., \ \ гор.)} = K_2SO_3 + 2K_2S + 3H_2O$ $P_4 + 3KOH_{(конц., \ \ гор.)} + 3H_2O = 3KH_2PO_2 + PH_3$ $2NaOH_{(конц., \ \ гор.)} + Si + H_2O = Na_2SiO_3 + 2H_2$ | — |

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/7501/f2477ca7e8d30589.png] {**Методы получения оснований**}

Основания можно получить, используя следующие методы:

- взаимодействие щелочных и щёлочноземельных металлов (образуются щёлочи):

$2Na + 2H_2O = 2NaOH + H_2 \uparrow$

Этот метод не находит практического применения ни в лаборатории, ни в промышленности.

- взаимодействие оксидов щелочных и щёлочноземельных металлов с водой (образуются щёлочи):

$CaO + H_2O = Ca(OH)_2$

- обменные реакции (можно получать и растворимые, и нерастворимые основания):

$Ba(OH)_2 + K_2SO_4 = 2KOH + BaSO_4 \downarrow$

$CuCl_2 + 2NaOH = Cu(OH)_2 \downarrow + 2NaCl$

- электролиз водных растворов солей активных металлов:

$2NaCl + 2H_2O = 2NaOH + H_2 \uparrow+ Cl_2 \uparrow$

В ходе электролиза солей металлов, стоящих в ряду напряжения до алюминия, на катоде происходит восстановление воды с выделением газообразного водорода и гидроксид-ионов. Катионы металла, образованные в ходе диссоциации соли, образуют с полученными гидроксид-ионами основания.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/8748/4b65d2672cef7080.png] {**Коротко о главном**}

Растворимые в воде основания — щёлочи. Нерастворимые основания выпадают из растворов в виде студенистых аморфных осадков.

Щёлочи и нерастворимые в воде основания различаются по химическим свойствам. Их общее свойство — взаимодействие с кислотами с образованием соли и воды.

Щёлочи можно получить при взаимодействии щелочных и щёлочноземельных металлов и их оксидов с водой, а также путём электролиза водных растворов солей.

Нерастворимые и растворимые основания можно получить с помощью обменных реакций.
