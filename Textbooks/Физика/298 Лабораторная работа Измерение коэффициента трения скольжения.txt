## Измерение коэффициента трения скольжения

### Набор оборудования:

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/196101/81bcc67490461ac1.png]

Используя брусок с крючком, динамометры №$1$ и №$2$, грузы №$1$ и №$2$, направляющую рейку, соберите экспериментальную установку для измерения коэффициента трения <https://foxford.ru/wiki/fizika/sila-treniya?srsltid=AfmBOootxRIwBnSUl-DNDo19XbvL1tQfzFdltdjo_rhI3itLTBhYkN_4> скольжения между бруском с двумя грузами и поверхностью рейки. Используйте поверхность рейки, обозначенную А. Абсолютная погрешность измерения силы при помощи динамометра №$1$ равна $\pm0,02$ Н, а при помощи динамометра №$2$ равна $\pm0,1$ Н.

В бланке ответов №$2$:

$1.~$сделайте рисунок экспериментальной установки, указав способ измерения силы трения скольжения;
$2.~$запишите формулу для расчёта коэффициента трения скольжения;
$3.~$укажите результаты измерения веса бруска с грузами и силы трения скольжения при движении бруска с грузами по поверхности рейки с учётом абсолютных погрешностей измерений;
$4.~$запишите значение коэффициента трения скольжения.

*В заданиях с тремя грузами или с поверхностью рейки, обозначенной Б, используется только один
динамометр №$2$

### Алгоритм:

$1.~$Выберите необходимое оборудование из избыточного набора.
$2.~$Определите вес $P$ бруска с грузами с помощью динамометра №$2$.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/195916/8a6560ae97839e4a.png]
$3.~$Определите силу тяги $F$ с помощью динамометра №$1$ при движении бруска с двумя грузами вдоль рейки.

Брусок нужно тянуть медленно и равномерно.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/195917/c4738e8e2247b8c7.png]

### Оформление на полный балл:

$1.~$Рисунок экспериментальной установки:

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/195915/7855a78ec69fb2a9.png]

$2.~$Формула для расчёта коэффициента трения скольжения:

$\begin{cases} P=mg\\ N=mg \end{cases} \rightarrow N=P $

Так как движение равномерное, то $F=F_{\text{тр}}$.

$F_{\text{тр}}=\mu N \rightarrow \mu=\dfrac{F_{\text{тр}}N}=\dfrac{FP}$

$3.~$Результаты измерения веса бруска с грузами и силы трения скольжения при движении бруска с грузами по поверхности рейки с учётом абсолютных погрешностей измерений:

$P=(3,0\pm0,1)$ Н

$F_{\text{тр}}=F=(0,9\pm0,02)$ Н

$4.~$Значение коэффициента трения скольжения:

$\mu=\dfrac{0,90\text{ Н}3,0\text{ Н}}\approx0,3$
