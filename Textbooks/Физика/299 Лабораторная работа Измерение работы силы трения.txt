## Измерение работы силы трения

### Набор оборудования:

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/196102/4860ab30143d3de9.png]

Используя брусок с крючком, динамометр №$2$, грузы №$1$, №$2$ и №$3$, направляющую рейку, соберите экспериментальную установку для измерения работы силы трения <https://foxford.ru/wiki/fizika/sila-treniya?srsltid=AfmBOootxRIwBnSUl-DNDo19XbvL1tQfzFdltdjo_rhI3itLTBhYkN_4> скольжения между бруском с тремя грузами и поверхностью рейки при перемещении бруска на расстояние $20$ см. Используйте поверхность рейки, обозначенную Б. Абсолютная погрешность измерения силы равна $\pm0,1$ Н, абсолютная погрешность измерения расстояния равна $\pm0,2$ см.

В бланке ответов №$2$:

$1.~$сделайте рисунок экспериментальной установки, указав способ измерения силы трения скольжения;
$2.~$запишите формулу для расчёта работы силы трения скольжения;
$3.~$укажите результаты измерения модуля перемещения бруска с грузами и силы трения скольжения при движении каретки с грузами по поверхности рейки с учётом абсолютных погрешностей измерения;
$4.~$запишите значение работы силы трения скольжения.

### Алгоритм:

$1.~$Выберите необходимое оборудование из избыточного набора.
$2.~$Определите силу тяги $F$ с помощью динамометра №$2$ при движении бруска с двумя грузами вдоль рейки. Брусок нужно тянуть медленно и равномерно.
$3.~$Расстояние возьмите из условия.

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/195919/b71c8a16b0d9f7c5.png]

### Оформление на полный балл:

$1.~$Рисунок экспериментальной установки:

[рисунок https://uploads-foxford-ru.ngcdn.ru/uploads/tinymce_file/file/195918/450b9e59ac3b0325.png]

$2.~$Формула для расчёта работы <https://foxford.ru/wiki/fizika/mehanicheskaya-rabota?srsltid=AfmBOooLXWiyTIwfTaD6FlaSNbzBtZU7z4-UvmofLqTJLyNZ5Pa9XvDE> силы трения скольжения:

Так как движение равномерное, то $F=F_{\text{тр}}$.

$A_{\text{тр}}=F_{\text{тр}}S\cos180^\circ=-F_{\text{тр}}S=-FS$

$3.~$Результаты измерения модуля перемещения бруска с грузами и силы трения скольжения при движении каретки с грузами по поверхности рейки с учётом абсолютных погрешностей измерения:

$S=(20,0\pm0,2)$ см

$F_{\text{тр}}=F=(2,4\pm0,1)$ Н

$4.~$Значение работы силы трения скольжения:

$A_{\text{тр}}=-2,4\text{ Н}\cdot0,2\text{ м}=-0,48$ Дж
