## Приставки

Приставка / префикс / **prefix** — часть слова, стоящая перед его корнем и дополняющая или изменяющая смысл слова. С помо­щью при­ста­вок мы можем образовывать новые сло­ва. Такой спо­соб сло­во­об­ра­зо­ва­ния назы­ва­ют **при­ста­воч­ным**.

Приставки имеют определённые значения.

| **Prefix** | **Meaning** | **Examples** |
| **anti-** + noun **anti-** + adjective | against / opposite | **__anti__-hero** — антигерой **__anti__social** — антиобщественный |
| **co-** + noun **co-** + verb | together | **__co__-worker** — коллега **to __co__operate** — взаимодействовать |
| **de-** + noun **de**- + verb | opposite / remove / reduce | **__de__vastation** — опустошение **__de__lay** — откладывать |
| **dis**- + noun **dis-** + adjective **dis-** + verb | negative / opposite | **__dis__appearance** — исчезновение **__dis__pleased** — недовольный **to __dis__like** — не любить |
| **ex-** +noun | previous | **__ex__-president** — бывший президент |
| **il-** +adjective | opposite | **__il__legal** — нелегальный |
| **im-** + adjective | opposite | **__im__possible** — невозможный |
| **in-** + adjective | opposite | **__in__dependent** — независимый |
| **inter-** + adjective | between | **__inter__national** — международный |
| **ir-** + adjective | opposite | **__ir__responsible** — безответственный |
| **mis-** + verb | wrongly / badly | **__mis__understand** — неправильно понять |
| **multi-** + noun **multi-** + adjective | many | **__multi__tasking** — многозадачность **__multi__cultural** / **__multi__-cultural** — многокультурный |
| **non-** + noun | not | **__non__-fiction** —документальная / научно-популярная / невыдуманная литература |
| **over-** + noun **over-** + adjective **over-** + verb | too much | **__over__reaction** — гиперреакция **__over__crowded** — переполненный **__over__estimate** — переоценивать |
| **post-** + noun **post-** + verb | after | **__post__graduate** — аспирант **__post__-date** — датировать более поздним числом |
| **pre-** + noun **pre-** + verb | before | **__pre__order** — предзаказ **__pre__heat** — подогревать |
| **re-** + verb | do again | **__re__read** — перечитать |
| **semi-** + noun **semi-** + adjective | half / partly | **__semi__-circle** — полукруг **__semi__-skimmed** (milk) — обезжиренное (молоко) |
| **sub-** + noun **sub-** + adjective | under / less | **__sub__marine** — подводная лодка **__sub__cultural** — субкультурный |
| **un-** + adjective **un-** + verb | opposite | **__un__popular** — непопулярный **__un__lock** — открывать замок |
| **under-** +verb | not enough | **__under__estimate** — недооценивать |

## Суффиксы

Суффикс / **suffix** — часть слова, стоящая после его корня и дополняющая или изменяющая смысл слова. С помо­щью суффиксов мы можем образовывать новые сло­ва. Такой спо­соб сло­во­об­ра­зо­ва­ния назы­ва­ют **суффиксальным**.

Суффиксы, как и приставки, имеют определённые значения.

| **Suffix** | **Function** | **Examples** |
| **-able** / **-ible** | noun + suffix = adjective verb + suffix = adjective | vision + ible = **vis__ible__** — видимый do + able = **do__able__** — выполнимый |
| **-al** | noun + suffix = adjective verb + suffix = noun | politics + al = **politic__al__** — политический survival + al = **surviv__al__** — выживание |
| **-ance** | verb + suffix = noun | appear + ance = **appear__ance__** — внешность |
| **-cian** | noun + suffix = noun | mucic + ician = **musi__cian__** — музыкант |
| **-ee** | verb + suffix = noun | employ + ee = **employ__ee__** — работник по найму |
| **-en** | noun + suffix = verb adjective + suffix = verb | strength + en = **strength__en__** — усиливаться loose + en = **loos__en__** — ослаблять |
| **-er** / **-or** / **-ar** | verb + suffix = noun | teach + er = **teach__er__** — учитель act + or = **act__or__** — актёр beg + ar = **begg__ar__** — попрошайка |
| **-eer** | noun + suffix = noun | mountain + eer = **mountaine__er__** — альпинист |
| **-ence** | adjective + suffix = noun | silent + ence = **sil__ence__** — молчание |
| **-ery** | adjective + suffix = noun | savage + -ery = **savag__ery__** — дикость |
| **-ful** | noun + suffix = adjective | help + ful = **help__ful__** — полезный |
| **-fy** | adjective + suffix = verb | simple + fy = **simpli__fy__** — упрощать |
| **-hood** | noun + suffix = noun | child + hood = **child__hood__** — детство |
| **-ic** | noun + suffix = adjective | drama + ic = **dramat__ic__** — драматический |
| **-ibility** | adjective + suffix = noun | flexible + -ibility = **flexib__ility__** — гибкость |
| **-ion** | verb + suffix = noun | elect + ion = **elect__ion__** — выборы |
| **-ise** | adjective + suffix = verb | general + ise = **general__ise__** — обобщать |
| **-ism** | noun + suffix = noun | feminine + ism = **femin__ism__** — феминизм |
| **-ist** | noun + suffix = noun adjective + suffix = noun verb + suffix = noun | art +ist = **art__ist__** — художник moder + ist = **modern__ist__** — модернист escape + ist = **escap__ist__** — эскапист |
| **-ive** | noun + suffix = noun verb + suffix = noun | effect + ive = **effect__ive__** — эффективный attract + ive = **attract__ive__** — привлекательный |
| **-less** | noun + suffix = adjective | help + less = **help__less__** — беспомощный |
| **-ly** | adjective + suffix = adverb | quick + ly = **quick__ly__** — быстро |
| **-ment** | verb + suffix = noun | appoint + ment = **appoint__ment__** — назначение |
| **-ness** | adjective + suffix = noun | polite + ness = **polite__ness__** — вежливость |
| **-ous** | noun + suffix = adjective | danger +ous = **danger__ous__** — опасный |
| **-ship** | noun + suffix = noun | friend + ship = **friend__ship__** — дружба |
| **-tion** / **-sion** | verb + suffix = noun | compete + tion = **competi__tion__** — соревнование decide + sion = **deci__sion__** — решение |
| -(**i**)**ty** | adjective + suffix = noun | loyal +ty = **loyal__ty__** — преданность similar + ity = **similar__ity__** — сходство |
| **-y** | verb + suffix = noun noun + suffix = adjective verb + suffix = adjective | injure — **injur__y__** травмировать — травма cloud + y = **cloud__y__** — облачный run + y = **runn__y__** — жидкий, текучий |
