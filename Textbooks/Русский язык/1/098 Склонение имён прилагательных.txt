Склонение имён прилагательных
Предмет: Русский язык
Раздел: Морфология
Источник: https://foxford.ru/wiki/russkiy-yazyk/sklonenie-imyon-prilagatelnyh
Обновлено: 2026-10-05

{**Имя прилагательное**} — это самостоятельная часть речи, которая обозначает **признак предмета** и отвечает на вопросы:

Какой? (красный, быстрый, красивый)

Чей? (мамин, лисий, отцов)

Какая? Какое? Какие?

**Полные** имена **прилагательные** изменяются по **родам**, **числам** и **падежам**, **согласуясь** в этих категориях с именами **существительными**, от которых зависят. **Окончание прилагательных можно определить по вопросу**, который к ним задается (кроме формы мужского рода именительного падежа):

важн**ое** (как**ое**?) событие, лучш**его** (как**ого**?) друга;

летн**их** (как**их**?) дней, крупн**ыми** (как**ими**?) узорами;

__хитр**ый** (как**ой**?) лис, непоседлив**ый** (как**ой**?) волчонок (мужской род, именительный падеж)__.

Если в окончании вопроса буква О, то в окончании прилагательного пишется О или Е; если в окончании вопроса буква И, то в окончании прилагательного пишется И или Ы

**Чтобы не ошибиться в написании безударных падежных окончаний прилагательных, запомните алгоритм:**

1. Определить, к какому **существительному** относится прилагательное.

2. Задать к прилагательному **вопрос** от определяемого слова, к которому оно относится.

3. Определить **окончание** вопроса.

4. Определить окончание прилагательного **по окончанию вопроса** и написать его.

## Окончания именительного падежа полных имён прилагательных

| **Единственное число** | **Множественное число** / **для всех родов** |
| **Мужской род** | **Женский род** | **Средний род** |
| Какой? | Какая? | Какое? | Какие? |
| -ЫЙ, -ИЙ, -ОЙ | -АЯ, -ЯЯ | -ОЕ, -ЕЕ | -ЫЕ, -ИЕ |
| пушист‑**ый** хвост / рыж-**ий** лис / больш‑**ой** учёный | дружелюбн‑**ая** белка / искренн-**яя** дружба | интересн‑**ое** увлечение / могуч-**ее** дерево | неразлучн‑**ые** товарищи / крепк-**ие** объятия |

## Родовые окончания кратких прилагательных

## Склонение имён прилагательных в единственном и множественном числе

| **Падеж** | **Единственное число** | **Множественное** **число** / **для всех родов** |
| **Мужской род** | **Женский род** | **Средний род** |
| **И.** | пушист-**ый** хвост / рыж-**ий** лис / больш-**ой** учёный | дружелюбн-**ая** белка / искренн-**яя** дружба | интересн-**ое** / увлечение / могуч-**ее** дерево | неразлучн-**ые** / товарищи / крепк-**ие** объятия |
| **Р.** | пушист-**ого** хвоста / рыж-**его** лиса / больш-**ого** учёного | дружелюбн-**ой** белки / искренн-**ей** дружбы | интересн-**ого** / увлечения / могуч-**его** дерева | неразлучн-**ых** / товарищей / креп-**ких** объятий |
| **Д.** | пушист-**ому** хвосту / рыж-**ему** лису / больш‑**ому** учёному | дружелюбн-**ой** белке / искренн-**ей** дружбе | интересн-**ому** / увлечению / могуч-**ему** дереву | неразлучн-**ым** / товарищам / крепк-**им** объятиям |
| **В.** | пушист-**ый** хвост / рыж-**его** лиса / больш‑**ого** учёного* | дружелюбн-**ую** белку / искренн-**юю** дружбу | интересн-**ое** / увлечение / могуч-**ее** дерево | неразлучн-**ых** / товарищей / крепк-**ие** объятия* |
| **Т.** | пушист-**ым** хвостом / рыж-**им** лисом / больш-**им** учёным | дружелюбн-**ой** белкой / искренн-**ей** дружбой | интересн-**ым** / увлечением / могуч-**им** деревом | неразлучн-**ыми** / товарищами / крепк-**ими** объятиями |
| **П.** | (о) пушист‑**ом** хвосте / (о) рыж-**ем** лисе / (о) больш‑**ом** учёном | (о) дружелюбн‑**ой** белке / (об) искренн‑**ей** дружбе | (об) интересн‑**ом** / увлечении / (о) могуч‑**ем** дереве | (о) неразлучн‑**ых** / товарищах / (о) крепк-**их** объятиях |

***Винительный** падеж прилагательных мужского рода единственного числа, а также множественного числа совпадает по форме с **именительным**, если прилагательное относится к **неодушевлённому** существительному, и с **родительным**, если прилагательное относится к **одушевлённому** существительному.

## Склонение притяжательных прилагательных с суффиксами ‑ИН‑ (‑ЫН‑), ‑ОВ‑ (‑ЕВ‑)

| **Падеж** | **Единственное число** | **Множественное число** / **для всех родов** |
| **Мужской род** | **Женский род** | **Средний род** |
| **И.** | папин⎕ друг / отцов⎕ галстук | папин-**а** запонка / отцов-**а** кружка | папин-**о** портмоне / отцов-**о** поручение | папин-**ы** коллеги / отцов-**ы** перчатки |
| **Р.** | папин-**а** (папин-**ого**) друга* / отцов-**а** галстука | папин-**ой** запонки / отцов-**ой** кружки | папин-**а** (папин-**ого**) портмоне* / отцов-**а** поручения | папин-**ых** коллег / отцов-**ых** перчаток |
| **Д.** | папин-**у** (папин-**ому**) другу* / отцов-**у** галстуку | папин-**ой** запонке / отцов-**ой** кружке | папин-**у** (папин-**ому**) портмоне* / отцов-**у** поручению | папин-**ым** коллегам / отцов-**ым** перчаткам |
| **В.** | папин-**ого** друга / отцов⎕ галстук** | папин-**у** запонку / отцов-**у** кружку | папин-**о** портмоне / отцов-**о** поручение | папин-**ых** коллег / отцов-**ы** перчатки** |
| **Т.** | папин-**ым** другом / отцов-**ым** галстуком | папин-**ой** запонкой / отцов-**ой** кружкой | папин-**ым** портмоне / отцов-**ым** поручением | папин-**ыми** коллегами / отцов-**ыми** перчатками |
| **П.** | (о) папин-**ом** друге / (об) отцов‑**ом** галстуке | (о) папин‑**ой** запонке / (об) отцов‑**ой** кружке | (о) папин-**ом** портмоне / (об) отцов‑**ом** поручении | (о) папин-**ых** коллегах / (об) отцов‑**ых** перчатках |

*В **именительном** падеже **притяжательные** прилагательные имеют **только краткую форму**, а в некоторых падежах **могут употребляться как в полной**, **так и в краткой форме**, хотя в современном русском языке краткая форма употребляется редко.

**Винительный** падеж **притяжательных** прилагательных **мужского** рода единственного числа, а также множественного числа совпадает по форме с **именительным**, если прилагательное относится к **неодушевлённому** существительному, и с **родительным**, если прилагательное относится к **одушевлённому** существительному:

**лисий** хвост — **лисий** детёныш;

вижу **лисий** хвост — вижу **лисьего** детёныша.

- **Фамилии** людей (Иванов, Петров, Сидоров), образованные от **собственных имён** (Иван, Пётр, Сидор) при помощи суффиксов -ОВ, -ИН **склоняются как притяжательные прилагательные**.

- **Названия городов и населённых пунктов** на -ИН, -ОВ(О), -ЕВ(О) (Хохлово, Камышин) в **мужском** и **среднем** роде склоняются во всех падежах **как притяжательные прилагательные** с этими суффиксами, но в **творительном** падеже они имеют окончания **существительных** -ОМ (под Хохловом, Бородином, Камышином).
