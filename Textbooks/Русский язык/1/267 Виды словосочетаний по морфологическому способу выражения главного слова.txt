Рассмотрим словосочетания. Какой частью речи выражено главное слово?

смотреть внимательно
большой мяч
весьма привлекательный

Узнать ответ

x
смотреть внимательно (смотреть (как?) внимательно — главное слово выражено глаголом)
x
большой мяч (мяч (какой?) большой — главное слово выражено существительным)
x
весьма привлекательный (привлекательный (насколько?) весьма — главное слово выражено прилагательным)

Таким образом, по морфологическому способу выражения главного слова словосочетания делятся на следующие группы:

| **Вид словосочетаний** | **Примеры** |
| {**Именные**} |
| **Главное слово — существительное** |
| сущ. + сущ. | **мест**о для встреч, **письмо** другу |
| сущ. + прил. | интересный **вопрос**, новое **платье** |
| сущ. + числит. | первый **министр**, вторая **полка** |
| сущ. + прич. | полученный **диплом**, выстраданное **счастье** |
| сущ. + нареч. | **яйцо** (какое?) всмятку, **кофе** (какой?) по-турецки |
| сущ. + инфинитив | **желание** (какое?) уехать, **мечта** (какая?) творить |
| **Главное слово — прилагательное** |
| прил.+ сущ. | **способный** к рисованию, **достойный** счастья |
| прил.+ инфинитив | **готов** бежать, **способен** видеть |
| прил.+ нареч. | безумно **красивый**, очень **чуткий** |
| **Главное слово — числительное** |
| **два** котёнка, **обе** подруги, **пятый** по счёту |
| **Главное слово — местоимение** |
| **что-то** из вещей, **каждый** из нас, **никто** из них |
| {**Глагольные**} |
| **Главное слово — глагол** |
| глаг. + инфинитив | **просить** спеть, **приказать** отпустить |
| глаг. + сущ. | **бежать** к дому, **торопиться** в школу, **писать** книгу, **разбирать** вещи |
| глаг. + нареч. | **улыбался** красиво, **бегает** быстро |
| {**Наречные**} |
| **Главное слово — наречие** |
| нареч. + сущ. | **задолго** до срока, **далеко** от берега |
| нареч. + нареч. | совершенно **секретно**, слишком **тихо** |
