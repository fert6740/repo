Такой вопрос невозможно задать в СПП с придаточными **присоединительными**. Эти придаточные содержат добавочную информацию, относятся ко всей главной части СПП и стоят после неё. Эти признаки сближают СПП с придаточными присоединительными и ССП. На то, что перед нами именно СПП с придаточным присоединительным, а не ССП, указывает наличие союзных слов что, отчего, зачем, почему в придаточной части:

[Мистер Фокс был в прекрасном расположении духа], (**что** предвещало интересные истории).

В зависимости от значения и того, что поясняется в главной части, различают следующие виды придаточных:

- определительные,
- изъяснительные,
- обстоятельственные.

## **Придаточное определительное**

Придаточное определительное предложение всегда относится к имени существительному (или другому слову в его роли) в главной части и отвечает на вопросы какой? какая? какое? какие? чей? Поясняемое существительное может быть как главным членом предложения, так и второстепенным. Придаточные определительные присоединяются только при помощи союзных слов: который, какой, что:

Бельчонок Белла заинтересовалась **игрой** (дополнение), (какой?) **которую** ей показал волчонок Макс.

**Игра**, (какая?) **которая** заинтересовала бельчонка Беллу, была показана ей волчонком Максом.

По синтаксической функции они соотносятся с определением.

Иногда в главной части СПП с придаточным определительным при определяемом существительном может быть указательное слово тот, этот, такой:

Прятки — это **та** игра, **которая** понравилась бельчонку Белле.

| Вид придаточного | **Определительное** |
| Вопрос | Какой? чей? |
| К чему относится придаточное | К существительному или местоимению |
| Средства связи | Союзы | |
| Союзные слова | Который, какой, чей, когда, где, куда, откуда, что |
| Указательные слова | Такой, тот, этот |
| Пример | Мистер Фокс не выпускал из рук книгу, (**которую** он давно хотел прочитать). Волчонок Макс смотрел на дорогу, (**откуда** должна была прийти бельчонок Белла). Енотику Петру нравилось жить в том городе, (**где** он родился и вырос) |

## Придаточное изъяснительное

Придаточное изъяснительное относится к словам в главной части СПП, которым необходимо дополнительное разъяснение (обычно — сказуемое), и отвечает на вопросы косвенных падежей. К главному предложению присоединяется с помощью подчинительных союзов (что, чтобы, словно) и союзных слов (где, когда, как):

Енотик Пётр **уверен**, (в чём?) **что** становится умнее с каждым годом.

По синтаксической функции придаточное изъяснительное соотносится с дополнением.

| Вид придаточного | **Изъяснительное** |
| Вопрос | Вопросы косвенных падежей |
| К чему относится придаточное | Обычно к сказуемому в главной части |
| Средства связи | Союзы | Что, как, будто, как будто, ли… или, то ли… то ли, как бы, как бы не, чтобы, чтобы не, ли, не… ли |
| Союзные слова | Почему, где, куда, откуда, насколько, что, кто, как, какой |
| Указательные слова | То (во всех формах) |
| Пример | Бельчонок Белла услышала, (**что** её зовут родители). Скажи мне, ветка Палестины, (**где** ты росла), (**где** ты цвела)? (М. Ю. Лермонтов) Бельчонок Белла задумалась, (**откуда** все знают её секрет) |

## Придаточные обстоятельственные

Придаточные обстоятельственные по значению и синтаксической функции соотносятся с обстоятельствами и отвечают на те же вопросы. Рассмотрим их.

| Вид обстоятельственного придаточного | **Времени** |
| Вопрос | С каких пор? когда? как долго? до каких пор? |
| К чему относится придаточное | Ко всей главной части или наречию со значением времени |
| Средства связи | Союзы | Когда, как, пока, едва, только, прежде чем, в то время как, до тех пор пока, с тех пор как, как вдруг |
| Союзные слова | Когда (если относится к тогда или другому наречию со значением времени в главной части) |
| Указательные слова | Тогда |
| Пример | (**Когда** волчонок Макс играет с ребятами), он забывает о времени |
| Вид обстоятельственного придаточного | **Места** |
| Вопрос | Куда? где? откуда? |
| К чему относится придаточное | К наречию, к указательному слову |
| Средства связи | Союзы | |
| Союзные слова | Где, куда, откуда |
| Указательные слова | |
| Пример | Мистер Фокс поспешил туда, (**где** его ждали друзья) |
| Вид обстоятельственного придаточного | **Цели** |
| Вопрос | Зачем? с какой целью? |
| К чему относится придаточное | Ко всей главной части |
| Средства связи | Союзы | Чтобы (чтоб), лишь бы, только бы, лишь бы только бы, для того чтобы, с тем чтобы, затем чтобы, дабы, лишь бы только |
| Союзные слова | |
| Указательные слова | Затем |
| Пример | Волчонок Макс научился плавать, (**чтобы** не бояться воды) |
| Вид обстоятельственного придаточного | **Причины** |
| Вопрос | Почему? отчего? |
| К чему относится придаточное | Ко всей главной части |
| Средства связи | Союзы | Потому что, ибо, благодаря тому что, оттого что, так как, поскольку, тем более что |
| Союзные слова | |
| Указательные слова | |
| Пример | Енотик Пётр торопился домой, (**потому что** там его ждала новая книга) |
| Вид обстоятельственного придаточного | **Меры и степени** |
| Вопрос | В какой мере? до какой степени? |
| К чему относится придаточное | К указательному слову |
| Средства связи | Союзы | Что, будто, словно, чтобы |
| Союзные слова | Сколько, насколько |
| Указательные слова | Так |
| Пример | Мистер Фокс рассказал о звёздах друзьям так, (**что** они заинтересовались этой темой) |
| Вид обстоятельственного придаточного | **Условия** |
| Вопрос | При каком условии? |
| К чему относится придаточное | Ко всей главной части |
| Средства связи | Союзы | Если (…то), раз, в случае если, когда (=если), коли, коль скоро |
| Союзные слова | |
| Указательные слова | |
| Пример | (**Если** мистер Фокс освободится вечером), то друзья смогут обсудить общие планы |
| Вид обстоятельственного придаточного | **Следствия** |
| Вопрос | Что из этого следует? |
| К чему относится придаточное | Ко всей главной части |
| Средства связи | Союзы | Так что |
| Союзные слова | |
| Указательные слова | |
| Пример | Волчонок Макс серьёзно сообщил об этом, (**так что** нельзя было не поверить ему) |
| Вид обстоятельственного придаточного | **Уступки** |
| Вопрос | Несмотря на что? вопреки чему? |
| К чему относится придаточное | Ко всей главной части |
| Средства связи | Союзы | Несмотря на то что, даром что, хотя (хоть), пусть, пускай / |
| Союзные слова | Что (бы) ни, кто (бы) ни, какой (бы) ни, сколько бы (ни), где (бы) ни, куда (бы) ни |
| Указательные слова | |
| Пример | Мистер Фокс вспомнил о произошедшем, (**хотя** не желал вспоминать об этом) |
| Вид обстоятельственного придаточного | **Сравнения** |
| Вопрос | Как что? подобно чему? |
| К чему относится придаточное | Ко всей главной части |
| Средства связи | Союзы | Как, будто, словно, точно, подобно тому как, так же как, как будто, как бы, будто бы, словно бы, как будто бы |
| Союзные слова | |
| Указательные слова | Так |
| Пример | Бельчонок Белла так заразительно засмеялась, (**точно** колокольчики зазвенели) |
| Вид обстоятельственного придаточного | **Образа действия** |
| Вопрос | Как? каким образом? |
| К чему относится придаточное | К указательному слову |
| Средства связи | Союзы | |
| Союзные слова | Как |
| Указательные слова | Так |
| Пример | Енотик Пётр рассказывал стихотворение так выразительно, (**как** его учили) |
