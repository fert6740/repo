Разноспрягаемые глаголы
Предмет: Русский язык
Раздел: Морфология
Источник: https://foxford.ru/wiki/russkiy-yazyk/raznospryagaemye-glagoly
Обновлено: 2026-10-05

Енотику Петру очень нравилось показывать свою осведомлённость. Сегодня он бежал к друзьям во двор с новостью об уникальности глаголов бежать и хотеть.


А вы знаете?


В чём же их уникальность? Да, это **разноспрягаемые глаголы**. Эти глаголы и приставочные производные от них (прибежать, захотеть) при изменении по лицам и числам имеют окончания то I, то II спряжения. Вот они. Давайте понаблюдаем.


Спряжение глагола **хотеть**.










| | По I спряжению ед. ч. | По II спряжению мн. ч. |






| 1-е лицо | хоч**у** | хот**им** |






| 2-е лицо | хоч**ешь** | хот**ите** |






| 3-е лицо | хоч**ет** | хот**ят** |






Спряжение глагола **бежать**.










| | По I спряжению | По II спряжению |






| 1-е лицо ед. ч. | | бег**у** |






| 2-е лицо ед. ч | | беж**ишь** |






| 3-е лицо ед. ч. | | беж**ит** |






| 1-е лицо мн. ч. | | беж**им** |






| 2-е лицо мн. ч | | беж**ите** |






| 3-е лицо мн. ч | бег**ут** | |






При морфологическом разборе указываем, что глагол разноспрягаемый.


**Внимание!** Часто с разноспрягаемыми глаголами путают глаголы с особой системой окончаний: есть, дать. Личные окончания в ед. ч. этих глаголов не относятся ни к одному из существующих в русском языке спряжений. Поэтому они не относятся к разноспрягаемым. При морфологическом разборе указываем их как **глаголы особого спряжения**.


Понаблюдаем за ними.


Спряжение глагола **есть.**










| | Ед. ч. | Мн. ч. |






| 1-е лицо | е**м** | ед**им** |






| 2-е лицо | е**шь** | ед**ите** |






| 3-е лицо | е**ст** | ед**ят** |






Спряжение глагола **дать**.










| | Ед. ч. | Мн. ч. |






| 1-е лицо | да**м** | дад**им** |






| 2-е лицо | да**шь** | дад**ите** |






| 3-е лицо | да**ст** | дад**ут** |






Таким образом, нужно различать разноспрягаемые глаголы, которые сочетают окончания и I, и II спряжений (хотеть, бежать и производные от них), и глаголы, изменяющиеся по особому спряжению (дать, есть и образованные от них).
