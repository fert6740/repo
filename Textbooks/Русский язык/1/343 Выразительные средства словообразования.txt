{**Словообразование**} — это раздел языкознания, изучающий способы создания новых слов на основе существующих в языке морфем (приставок, корней, суффиксов и т.д.). Это процесс, который позволяет языку развиваться и пополнять словарный запас.

Сравните слова:

- собака, собачонка, собачища, собаченция;
- штука, штучка, штуковина.

Суффикс придаёт слову смысловую и стилистическую окраску.

Нейтральное существительное собака с прибавлением суффикса **-онк-** получило новое значение с отрицательной (пренебрежительной) окраской: собачонка — маленькая собака. С суффиксом **-ищ-** слово тоже поменяло значение: собачища — что-то большое, страшное, а суффикс **-енциj-** придал слову шутливую, ироничную или даже пренебрежительную окраску.

Существительное штука с прибавлением суффикса **-к-** также приобретает новые значения. В первом случае — уменьшительное от штуки: Он попросил одну штучку. Во втором — фамильярно-разговорное штучка: Сейчас можно увидеть столичную штучку (Н. В. Гоголь). Суффикс **-овин-** придал разговорному слову штуковина пренебрежительную окраску.

## Приемы словообразования и их характеристика

| Приёмы / (возможности словообразования) | Характеристика | Примеры |
| ### Семантизация морфем | Установить смысл, значение слова, использовать морфемы с разным значением, чтобы привлечь внимание читателя к конкретному слову | 1) прыгать: - допрыгаться (отрицательное значение, найти неприятности), - упрыгаться (убавление, устать), - отпрыгаться (закончить); 2) рисовать: - изрисовать (исчерпанность), - вырисовать (детально, старательно) |
| Иногда сопровождают графическим средством разрыва, выделением морфемы (чаще всего приставки) дефисом, что расходится с правилами орфографии | Настоящему человеку присуще сочувствие. Со‑чувствовать — значит чувствовать вместе с другими (И. Грекова). Рас-стояние: вёрсты, мили… / Нас рас-ставили, рас‑садили, / Чтобы тихо себя вели / По двум разным концам земли (М. И. Цветаева) |
| ### Использование суффиксов ### | Автор использует суффиксы, образующие формы имён существительных, качественных прилагательных и наречий с особой эмоциональной окраской: 1) использование суффиксов субъективной оценки помогает выразить определённое отношение говорящего к предмету, признаку или качеству и придаёт словам экспрессивную окраску: — уменьшительно-ласкательную; — преувеличения, преуменьшения; — пренебрежения, презрения, иронии; — неодобрения; — вульгарного просторечия | 1. Суффиксы имён существительных: **-ец-** (любимец), / **-чик-** (сарафанчик, стульчик), / **-ик-** (автоматик, столик), / **-ок-** (рожок, кулачок), / -**иц-** (девица, молодица), / **-к-** (тучка, сетка), / **-инк-** (пушинка, песчинка), / **-очк-** (луночка, досточка), / -**ишк**- (платьишко), / **-ышк-** (гнездышко, горлышко), / **-ушк-**, **-юшк-** (дедушка, полюшко), / **-оньк-**, **-еньк-** (лисонька, доченька), / **-онк-**, **-ёнк-** (клячонка, шубёнка), / **-ц-**, **-иц-**, **-ец-** (зеркальце, компотец, ружьецо), / **-ашк-** (милашка), / **-очк-**, **-ечк-**, **-ушек-** (вазочка, имечко, воробушек), / **-ин-** (домина), / **-ищ-** (городище), / **-ак-**, **-як-** (кусака, кривляка). 2. Суффиксы имён прилагательных: **-еньк-**, **-оньк-** (полненький, тощенький), / **-ёхоньк-**, **-ёшеньк-** (мокрёхонький, радёшенький). 3. Суффиксы наречий: **-еньк(о)-**, **-оньк(о)-** (давненько, легонько), / **-енечк(о)-**, **-онечк(о)-** (хорошенечко, тихонечко), / **-оват(о)**, **-еват(о)** (маловато, щеголевато) |
| 2) использование выразительной возможности суффиксов — для придания стилистической окраски, не свойственной мотивирующему слову; — для указания на стиль; — для указания на сферу использования слов или место в лексическом запасе | - сынулька (уменьш.-ласк.) — сын, бухгалтерша (прост.) — бухгалтер; - директор (общеупотр.) — директриса (разг.), плавкий (общеупотр.) — плавкость (научн., термин), / игра (общеупотр.) — игрище (разг.); - расход — расходник (проф.), мультфильм — мультик (разг.), мультяшка (жарг.), / дерзостный (уст.) — дерзкий |
| ### Авторское словообразование ### ### ### | Авторские слова используют для особой выразительности или языковой игры. Словообразование авторских слов: а) новые слова звучат так же или почти так же, как привычные, при этом автор использует обычную основу и словообразовательные аффиксы | Обольстительная сеть, / золотая ненасыть. / Было нечего надеть, / стало — некуда носить (А. А. Вознесенский). / Ненасытный — ненасыть (образовано по модели нечистый — нечисть, созвучно со словом ненастье) |
| б) новые слова созданы по самым популярным словообразовательным моделям, например: телёнок — коровёнок, т .е. «сын» коровы | Там, где капустные грядки / Красной водой поливает восход, / Кленёночек маленький матки / Зелёное вымя сосёт (С. А. Есенин). Кленёночек — клён и ребёночек, т. е. клён ещё совсем маленький |
| в) новые слова не соответствуют словообразовательной норме | К зелёным ветвям, закипая внизу, / ползут небывало зелёные лозы — / китайское ЧЬЕН, и татарское ЗУ, / и мхи диалектов эхоголосых (С. И. Кирсанов). Эхоголосые — эхо + голос(ые) по аналогии с деривационной моделью слов звонкоголосый, длинноногий, синеглазый: основа прилагательного + основа существительного + нулевой суффикс |
| г) новые слова образованы от имён собственных по типу строения глаголов повелительного наклонения, могут соответствовать или не соответствовать норме словообразования | Усадьба ночью, чингисхань! / Шумите, синие берёзы. / Заря ночная, заратустрь! / А небо синее, моцарть! / И, сумрак облака, будь Гойя! / Ты ночью, облако, роопсь! (В. В. Хлебников) Чингисхань, заратустрь, моцарть, роопсь —перестроены по типу строения глагола повелительного наклонения: Чингисхан, Заратустра, Моцарт, Роопс + глагольная форма повелительного наклонения |
| ### | д) автор создает новые однокоренные слова к привычным, опираясь или не опираясь на словообразовательную норму | Какая ночь! Я не могу, не спится мне, / Какая лунность! / Ещё как будто берегу в душе / Утраченную юность (С. А. Есенин). / Слово лунность по типу словообразовательной цепочки слов век — вечность, вода — водность, злоба — злобность |
