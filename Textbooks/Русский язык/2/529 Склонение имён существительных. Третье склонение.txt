**В этой статье ты узнаешь:**

- какие существительные относятся к третьему склонению;

- правописание падежных окончаний имён существительных третьего склонения.

## Что такое склонение имени существительного

**Имя существительное** — это изменяемая часть речи.
Существительные могут изменяться по числам и падежам.

**Склонение** — это изменение имени существительного по вопросам падежей.

При склонении у существительных изменяется окончание. Слова, у которых совпадают окончания в разных падежах, принято делить на группы по типу склонения.

| **1-е склонение** | **2-е склонение** | **3-е склонение** |
| сущ. в И. п., ед. ч. / ж. р. или м. р. / с окончаниями **-а, -я** звезд**а**, пашн**я** / юнош**а**, мужчин**а**, дяд**я** | сущ. в И. п., ед. ч. / м. р. с нулевым окончанием и ср. р. с окончаниями **-о, -е** парус⎕ , ветер⎕ / мор**е**, судн**о** | сущ. в И. п., ед. ч. / ж. р. с нулевым окончанием; / слова оканчиваются на **Ь**. мыш**ь**⎕, рож**ь**⎕, ноч**ь**⎕ доч**ь**⎕, морков**ь**⎕ |

## Как определить склонение имени существительного

Для этого нужно:

1. Поставить существительное в начальную форму.

2. Определить род имени существительного.

3. Выделить окончание.

4. Определить, к какому из трёх видов склонения относится существительное.

## **Имена существительные третьего склонения**

Имена существительные в именительном падеже единственного числа **женского рода** с нулевым окончанием относятся к **третьему склонению**.

**Правописание падежных окончаний имён существительных третьего склонения**

Чтобы правильно писать окончания существительных третьего склонения, нужно уметь определять падеж и знать падежные окончания имён существительных третьего склонения.

| **Падеж** | **Женский род** | **Окончания** |
| И. п. (есть) / **кто? что?** | мышь⎕ / капе́ль⎕ | **⎕ нулевое окончание** |
| Р. п. (нет) / **кого? чего?** | мыш**-и** / капел**-и** | **-и** |
| Д. п. (дать) / **кому? чему?** | мыш**-и** / капел**-и** | **-и** |
| В. п. (вижу) / **кого? что?** | мышь⎕ / капе́ль⎕ | **⎕ нулевое окончание** |
| Т. п. (доволен) / **кем? чем?** | мышь**-ю** / капель**-ю** | **-ю** |
| П. п. (думаю) / **о ком? о чём?** | о мыш**-и** / о капел**‑и** | **-и** |

**Ударные и безударные** падежные окончания имён существительных третьего склонения в одном и том же падеже пишутся **одинаково**.

Ударные падежные окончания существительных третьего склонения помогают проверить написание безударных окончаний имён существительных третьего склонения.

без любв**ú** — без рáдост**и**, к степ**ú** — к плóщад**и**

## Как правильно написать окончание

Давай потренируемся: Выглянула щука из **проруби**.

1. Определи склонение имени существительного.
Н. ф. прорубь — сущ. ж. р., окончание нулевое — 3-е склонение.
2. Определи падеж имени существительного.
Вынырнула из (чего?) проруби — Р. п.
3. Примени правило написания безударных падежных окончаний.
Падежные окончания сущ. 3-го скл. в Р. п. **-и**
→ выглянула из проруб**и**.

## **Проверь себя**

**Задание 1.** Какие существительные относятся к третьему склонению?
**Задание 2.** Вставь букву в безударных окончаниях имён существительных третьего склонения.

О спелой грозд…, делился радость…, ждали новост…, рассказ о рыс…, руки матер…, зашагал без трост…, без фальш…, дождались глухой полноч…, в таёжной глуш…, о богатой залеж… минералов, с помощь… друзей, не хватило гуаш… .

Ответы

**1.** Имена существительные в именительном падеже единственного числа **женского рода** с нулевым окончанием относятся к **третьему склонению**.

**2.** О спелой грозд**и** (П. п.), делился радость**ю** (Т. п.), ждали новост**и** (Р. п.), рассказ о рыс**и** (П. п.), руки матер**и** (Р. п.), зашагал без трост**и** (Р. п.), без фальш**и** (Р. п.), дождались глухой полноч**и** (Р. п.), в таёжной глуш**и** (Р. п.), о богатой залеж**и** (П. п.) минералов, с помощь**ю** (Т. п.) друзей, не хватило гуаш**и** (Р. п.).
