## Какие бывают типы текстов

В русском языке выделяют три **типа текста (типа речи)**:

- повествование;

- описание;

- рассуждение

## Сравнительная таблица типов текста

| **Описание** | **Повествование** | **Рассуждение** |
| {1. Определение} |
| Описание — это тип текста, в котором описываются признаки предметов, явлений, состояния человека | Повествование — это тип текста, в котором описываются события в определённой последовательности | Рассуждение — это тип текста, в котором объясняется или доказывается что-либо. |
| {2. Цель текста} |
| Описать признаки предметов, процессов, состояний | Рассказать о каком-то событии | Объяснить какие-либо утверждения |
| {3. На какие вопросы даёт ответ} |
| Какой? Какая? Какое? Какие? | Что произошло? | Почему? Зачем? |
| {4. Как строится текст} |
| 1. Вступление. Общее представление о предмете (каков предмет и почему он требует описания) / 2. Отдельные его признаки / 3. Авторская оценка, заключение (каково впечатление) | 1. Вступление, зачин (с чего началось) / 2. Развитие событий (как развивались события) / 3. Заключение, развязка (чем дело закончилось) | 1. Тезис (то, что доказывается, объясняется) / 2. Доказательства (аргументы, доводы, обоснование, объяснение) / 3. Вывод (заключение, обобщение) |
| {5. Особенности языка} |
| - много определений (чаще всего прилагательных) - слова, обозначающие качества, свойства предмета: существительных, прилагательных, наречий - глаголы в форме несовершенного вида прошедшего и настоящего времени - слова в переносном значении, сравнение - однородные члены предложения - восклицательные предложения | - много глаголов: глаголы совершенного вида, глаголы в форме прошедшего времени - диалог | - слова, указывающие на связь мыслей (во-первых, итак и др.) - много союзов со значением причины, следствия (поэтому, что, потому что, для того чтобы, так как) |
| {6. В каком стиле используется} |
| В разговорном и книжном стилях | В разговорном и художественном стилях | В научном стиле и его разновидностях |
