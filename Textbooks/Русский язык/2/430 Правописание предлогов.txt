Правописание предлогов
Предмет: Русский язык
Раздел: Орфография
Источник: https://foxford.ru/wiki/russkiy-yazyk/pravopisanie-predlogov
Обновлено: 2026-10-05

{**Предлоги**} - это служебные слова.

### Предлоги делятся на несколько категорий в зависимости от различных критериев:

| **Критерий** | **Вид предлога** | **Примеры** | **Примечание** |
| **По происхождению** | **Первообразные** | в, на, за, под, от, к, у, с, по, над, при, перед | Не образованы от других частей речи |
| | **Производные** | вблизи (нареч.), ввиду (отым.), благодаря (деепр.) | Образованы от других частей речи |
| **По составу** | **Простые** | в, на, из, через | Одно слово |
| | **Составные** | в течение, в связи с, по отношению к | Два и более слова |
| **По значению** | **Пространственные** | в (в дом), на (на столе), под (под столом), между (между домами) | Указывают на место |
| | **Временные** | в (в понедельник), через (через час), во время (во время дождя) | Указывают на время |
| | **Причинные** | из-за (из-за дождя), благодаря (благодаря тебе), вследствие (вследствие аварии) | Указывают на причину |
| | **Целевые** | для (для друга), ради (ради победы), во имя (во имя справедливости) | Указывают на цель |
| | **Образа действия** | с (с радостью), без (без страха), по (по правилам) | Указывают на способ |
| | **Сравнительные** | вроде (вроде меня), подобно (подобно птице), наподобие (наподобие зонтика) | Выражают сравнение |
| | **Уступительные** | несмотря на (несмотря на дождь), вопреки (вопреки совету) | Указывают на условие |
| **По управлению падежами** | **С одним падежом** | **Родительный** – без, для, до, из / **Дательный** – к, благодаря / **Винительный** – про, через / **Творительный** – над, перед / **Предложный** – о, при | Управляют только одним падежом |
| | **С несколькими падежами** | в (вин. – "в лес", предл. – "в лесу") / на (вин. – "на стол", предл. – "на столе") | Могут требовать разных падежей в зависимости от контекста |

Сложные предлоги **из-за, из-под** пишутся через дефис: ошибся из-за невнимательности; выскочил из-под дивана.

Производные предлоги пишутся слитно или раздельно, их написание нужно запоминать. При этом важно отличать предлоги от других частей речи. Для проверки можно использовать синонимы некоторых производных предлогов.

| **Пишутся слитно** | **Пишутся раздельно** |
| **ввиду** (из-за, по причине) обильного снегопада | **иметь в виду** **в виду** (около, вблизи) памятника |
| **вследствие** (из-за) допущенной ошибки | свернуть **в виде** треугольника |
| **вместо** (взамен) шляпы | **в силу** сложившихся обстоятельств |
| **взамен** сломанной ручки | **в целях** повышения качества образования |
| **вроде** (наподобие) шара | **в связи** с предстоящим тестированием |
| **наподобие** (вроде) клюшки | **в продолжениЕ** нашего разговора размышлял **в продолжениЕ** часа (НО: в продолжениИ (в следующей части) сериала) |
| **насчет** (по поводу, в отношении) экзамена | выполненная **в течениЕ** дня работа (НО: в течениИ разговора неожиданный поворот) |
| **сверх** меры | **в заключениЕ** поблагодарить слушателей (НО: в заключении врача рекомендации по лечению) |
| **помимо** домашнего задания | **в завершениЕ** выступления |
| **невзирая** на прогноз(вопреки прогнозу) | **в отличиЕ** от многих |
| **несмотря** на запрет (вопреки запрету) | **не смотря** (не глядя) на стоящих рядом людей (НЕ с деепричастием) |
| **навстречу** (Кому?) другу **навстречу** (Чему?) своей судьбе | **на встречу** (С кем?) с одноклассником **на встречу** (С чем?) с будущим |

Примеры проверки написания некоторых производных предлогов:
**Ввиду** экономического кризиса ВВП страны уменьшился. = Из-за экономического кризиса ВВП страны уменьшился; По причине экономического кризиса ВВП страны уменьшился;

Туристы в Суздале гуляли **в виду** кремля. = Туристы в Суздале гуляли вблизи кремля. = Туристы в Суздале гуляли около кремля;

Башня в уральском Невьянске **вроде** Пизанской;

Все в семье подумывали **насчёт** покупки нового автомобиля. = Все в семье подумывали о покупке нового автомобиля;

**Вследствие** пробок жители мегаполисов теряют много времени. = По причине пробок жители мегаполисов теряют много времени. = Из-за пробок жители мегаполисов теряют много времени.
