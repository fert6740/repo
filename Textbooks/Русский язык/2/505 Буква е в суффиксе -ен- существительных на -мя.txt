Буква е в суффиксе -ен- существительных на -мя
Предмет: Русский язык
Раздел: Орфография
Источник: https://foxford.ru/wiki/russkiy-yazyk/bukva-e-v-suffikse-en-sushchestvitelnyh-na-mya
Обновлено: 2026-10-05

У разносклоняемых существительных, оканчивающихся на **-мя**, в родительном, дательном, творительном и предложных падежах единственного числа появляется формообразующий суффикс **-ен-**, который входит в основу слова: нет знамени, вспоминаю о племени.









| Падеж | Единственное число |





| Им. п. | знамя / племя |





| Род. п. | знам**ен**и / плем**ен**и |





| Дат. п. | знам**ен**и / плем**ен**и |





| Вин. п. | знамя / племя |





| Твор. п. | знам**ен**ем / плем**ен**ем |





| Пред. п. | о знам**ен**и / о плем**ен**и |






Во множественном числе у этих существительных суффикс **-ен-/-ён-** появляется во всех падежах: новые времена, много имён. Исключением является форма родительного падежа слов семя и стремя, она образуется с помощью суффикса **-ян-**: семян, стремян.









| Падеж | Множественное число |





| Им. п. | времена / семена |





| Род. п. | времён / сем**ян** |





| Дат. п. | временам / семенам |





| Вин. п. | времена / семена |





| Твор. п. | временами / семенами |





| Пред. п. | о временах / о семенах |
