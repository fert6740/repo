Виды ошибок. Речевые ошибки
Предмет: Русский язык
Раздел: Культура речи
Источник: https://foxford.ru/wiki/russkiy-yazyk/vidy-oshibok-rechevye-oshibki
Обновлено: 2026-10-05

Волчонок Макс благодарен енотику Петру, потому что тот помог ему починить велосипед. Счастливый малыш побежал домой и встретил мистера Фокса. «Енотик Пётр — мой самый заклятый друг, теперь я не буду обижаться на него», — сообщил он старшему товарищу. Мистер Фокс улыбнулся и рассказал волчонку, что заклятых друзей не бывает, они верные. А потом поведал о речевых ошибках, которые можно допустить в общении.


{**Речевая ошибка**} — это неправильное употребление слов. В отличие, например, от грамматической, ее можно увидеть только в контексте.










| **Вид ошибки** | **Суть ошибки** | **Пример** |






| **Лексические** | Нарушения правил лексики, нарушение правил согласования: / — плеоназм; / / / — тавтология; / / — нарушение лексической сочетаемости; / / — ошибки в употреблении фразеологизмов; / / — неправильное употребление иноязычных слов, неологизмов, устаревших слов; / — алогизм (соединение несовместимых понятий); / / — неточное употребление синонимов; / — употребление паронимов. | / / / / предчувствовать заранее, неожиданный сюрприз, памятный сувенир / писатель пишет, проливной ливень / Эта книга играла большое значение для енотика Петра (играла роль). / С ним были строги, его держали в грязном теле (держать в чёрном теле). / Мистер Фокс испытывал в этот момент специфические чувства. / / / Енотик Пётр был отъявленным простаком (отъявленный плут). / / Кто крайний? (Правильно: Кто последний?) / годовой малыш (годовалый), каменистые ступеньки (каменные) |






| **Стилистические** | Отступление от норм стилистики: / — нарушение единства стиля; / / — злоупотребление разговорными словами; / / — немотивированное употребление книжных слов; / — употребление канцеляризмов; / — многословие. / / | / / / Татьяна Ларина из деревни подалась в Петербург (подалась — разг.). / Друзья мозговали долго и приняли верное решение. / / У волчонка Макса ручка не функционирует. / / На зелёных насаждениях появились первые листочки. / Грибы нередки в наших лесах. Они встречаются часто. |
