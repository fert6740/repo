Этот разряд очень любит порядок,
Он для неё, словно мёд, очень сладок.
Который по счёту? Первый, пятый, седьмой,
А может быть, даже сто сорок восьмой.
Эта группа просто исключительная,
Называется **порядковое числительное**!

С. И. Демченко

## Значение порядковых числительных

Порядковые числительные называют порядковый номер предметов при счёте и отвечают на вопрос какой по счёту? (первый год, второй сезон, двадцатая серия, сто восемьдесят седьмой день).

Образуются они от количественных числительных (кроме слов первый и второй):

шесть → шест**ой**, восемь → восьм**ой**, сто → сот**ый**, тридцать пять → тридцать пят**ый**.

## Изменение порядковых числительных

Порядковые числительные изменяются по родам, числам и падежам и склоняются как имена прилагательные:

| Им. п. | шестой урок | одиннадцатый день |
| Род. п. | шестого урока | одиннадцатого дня |
| Дат. п. | шестому уроку | одиннадцатому дню |
| Вин. п | шестой урок | одиннадцатый день |
| Тв. п. | шестым уроком | одиннадцатым днём |
| Пред. п. | о шестом уроке | об одиннадцатом дне |

При склонении составных порядковых числительных изменяется только последнее слово:

| Им. п. | двести сорок пятая страница | **одна** тысяча девятьсот девяностый год / **тысяча** девятьсот девяностый год |
| Род. п. | двести сорок пятой страницы | **одна** тысяча девятьсот девяност**ого** года / **тысяча** девятьсот девяност**ого** года |
| Дат. п. | двести сорок пятой странице | **одна** тысяча девятьсот девяност**ому** году / **тысяча** девятьсот девяност**ому** году |
| Вин. п | двести сорок пятую страницу | **одна** тысяча девятьсот девяностый год / **тысяча** девятьсот девяностый год |
| Тв. п. | двести сорок пятой страницей | **одна** тысяча девятьсот девяност**ым** годом / **тысяча** девятьсот девяност**ым** годом |
| Пред. п. | о двести сорок пятой странице | **одна** тысяча девятьсот девяност**ом** годе / **тысяча** девятьсот девяност**ом** годе |

При склонении сложного порядкового числительного первая его часть всегда имеет форму родительного падежа (кроме числительных сорок, девяносто, сто); вторая часть имеет окончание, которое зависит от формы порядкового числительного (рода, числа и падежа):

| Им. п. | семидесятый год | шестисотый покупатель |
| Род. п. | семидесят**ого** года | шестисот**ого** покупателя |
| Дат. п. | семидесят**ому** году | шестисот**ому** покупателю |
| Вин. п | семидесят**ый** год | шестисот**ого** покупателя |
| Тв. п. | семидесят**ым** годом | шестисот**ым** покупателем |
| Пред. п. | о семидесят**ом** годе | о шестисот**ом** покупателе |

При склонении порядковых числительных, образованных от количественных сорок, девяносто, сто, в единственном числе мужского рода и во множественном числе у одушевлённых числительных совпадают формы родительного и винительного падежей, у неодушевлённых — формы именительного и винительного:

| Падеж | Единственное число |
| М. р. | Ж. р. | Ср. р. |
| Им. п. | сороковой маршрут | девяностая квартира | сотое условие |
| Род. п. | сорокового маршрута | девяностой квартиры | сотого условия |
| Дат. п. | сороковому маршруту | девяностой квартире | сотому условию |
| Вин. п | сорокового жителя (одуш.) / сороковой маршрут (неодуш.) | девяностую квартиру (ученицу) | сотое условие |
| Тв. п. | сороковым маршрутом | девяностой квартирой | сотым условием |
| Пред. п. | сороковом маршруте | девяностой квартире | сотом условии |
| Падеж | Множественное число |
| Им. п. | сороковые годы | девяностые секунды | сотые экземпляры |
| Род. п. | сороковых годов | девяностых секунд | сотых экземпляров |
| Дат. п. | сороковым годам | девяностым секундам | сотым экземплярам |
| Вин. п | сороковых горожан (одуш.) / сороковые годы (неодуш.) | девяностых жителей (одуш.) / девяностые секунды (неодуш.) | сотых сельчан (одуш.) / сотые экземпляры (неодуш.) |
| Тв. п. | сороковыми годами | девяностыми секундами | сотыми экземплярами |
| Пред. п. | сороковых годах | девяностых секундах | сотых экземплярах |

В словосочетании порядкового числительного и существительного, обозначающего месяц года, имя существительное ставится в родительном падеже:

| Им. п. | второе апреля |
| Род. п. | второго апреля |
| Дат. п. | второму апреля |
| Вин. п | второе апреля |
| Тв. п. | вторым апреля |
| Пред. п. | о втором апреля |

## Синтаксическая роль

В предложении порядковое числительное может выполнять роль определения или входить в состав какого-либо члена предложения:

[рисунок Рисунки/687-1.png]

(Запись какую? сто двадцать седьмую.)

Порядковые числительные, обозначающие даты, вместе с существительными являются обстоятельствами времени:

[рисунок Рисунки/687-2.png]

(Было совершено когда? тридцатого августа.)

Порядковые числительные могут быть частью составного именного сказуемого:

[рисунок Рисунки/687-3.png]

Также порядковые числительные могут выполнять роль подлежащего, образуя цельное словосочетание:

__Двенадцатое апреля__ — День космонавтики.
