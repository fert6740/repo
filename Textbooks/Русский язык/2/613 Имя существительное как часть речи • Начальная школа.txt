**В этой статье ты узнаешь:**

- что обозначает и на какие вопросы отвечает имя существительное;

- его морфологические признаки;

- что такое «начальная форма» имени существительного;

- какую роль оно выполняет в предложении.

{**Имя существительное**} — это самостоятельная часть речи, которая **обозначает предмет** и отвечает на вопросы **кто? что?**
Кто? школьник, дедушка, синица, лягушка
Что? карандаш, берёза, язык, мысль

### Морфологические признаки имени существительного

Ранним утром мистер Фокс и енотик Пётр получили письмо от дедушки мистера Фокса. В письме дедушка Корсак рассказывал о своём путешествии на Кавказ и восхождении на Эльбрус.

## Имя существительное обозначает предметы

| Которые отвечают на вопрос **кто?** / мистер Фокс, дедушка, Корсак, енотик Пётр | Которые отвечают на вопрос **что?** / утро, письмо, путешествие, Кавказ, восхождение, Эльбрус |
| ⇓ | ⇓ |
| **Одушевлённое** имя существительное | **Неодушевлённое** / имя существительное |

## Имя существительное обозначает предметы

| Которые пишутся с заглавной буквы и обозначают имя или название конкретного объекта: / Фокс, Корсак, Пётр, Кавказ, Эльбрус | Которые пишутся со строчной буквы и обозначают остальные объекты: / енотик, письмо, дедушка, мистер, путешествие, восхождение |
| ⇓ | ⇓ |
| Имя **собственное** | Имя **нарицательное** |

## Имя существительное принадлежит определённому роду

| **Мужской род** / мистер Фокс / Корсак / енотик Пётр | **Женский род** / берёза, / Россия, / мама | **Средний род** / письмо, / путешествие, / восхождение |

## Имя существительное может обозначать

| **Один** предмет / енотик, берёза, путешествие | **Два** или **несколько** предметов / енотики, берёзы, путешествия |
| ⇓ | ⇓ |
| Существительное / **в единственном числе** | Существительное / **во множественном числе** |

## Имя существительное может изменяться по падежам

| Именительный падеж | **кто?** / **что?** | мама, / берёза, язык, / письмо |
| Родительный падеж | **кого?** / **чего?** | мамы, / берёзы, языка, / письма |
| Дательный падеж | **кому?** / **чему?** | маме, / берёзе, языку, / письму |
| Винительный падеж | **кого?** / **что?** | маму, / берёзу, язык, / письмо |
| Творительный падеж | **кем?** / **чем?** | мамой, / берёзой, языком, / письмом |
| Предложный падеж | **о ком?** / **о чём?** | о маме, / о берёзе, о языке, / о письме |

## Начальная форма имени существительного

Форма существительного в единственном числе и именительном падеже (отвечает на вопросы **кто? что?**) называется **начальной формой** имени существительного.

## **Роль имени существительного в предложении**

Имя существительное в **именительном падеже**, отвечающее на вопрос **кто? что?**, в предложении является **подлежащим**.

Если имя существительное стоит **в другом падеже**, то оно может выполнять функцию **второстепенного члена** предложения.
