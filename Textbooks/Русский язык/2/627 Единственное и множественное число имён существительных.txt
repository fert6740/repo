Единственное и множественное число имён существительных
Предмет: Русский язык
Раздел: Русский язык в начальной школе
Источник: https://foxford.ru/wiki/russkiy-yazyk/edin-mnoges-chislo
Обновлено: 2026-10-05

**В этой статье ты узнаешь:**

- что такое число имён существительных;

- какими способами можно определить или изменить число имён существительных;

- какие имена существительные могут иметь только форму одного числа;

- как определить число несклоняемых имён существительных.

Мистер Фокс пригласил наших героев на чай. На столе стояли конфеты, кексы и фрукты.
Белла, Пётр и Макс взяли по одной конфете, по одному кексу и по одному яблоку.
Пётр, как обычно, проявил любопытство:
— На столе всего было много! А теперь у каждого из нас стало по одному предмету! Мистер Фокс, а как называются предметы, когда они по одному и когда их много?

Давай вместе с ребятами послушаем мистера Фокса.

[рисунок Рисунки/627-3.png]

Посмотри на картинку. Слева ты видишь предметы по одному, и слово рядом называет один предмет. Справа несколько предметов, и слова показывают, что их много.
Конфета, кекс, яблоко, чашка — имена существительные, которые называют один предмет. Это форма **единственного числа.**
Конфеты, кексы, яблоки, чашки — имена существительные, которые называют несколько предметов. Это форма **множественного числа.**

Имена существительные изменяются **по числам**. То есть они имеют форму единственного и множественного числа. При изменении имени существительного по числам изменяется и его окончание.

Имя существительное в единственном числе обозначает один предмет.
Имя существительное во множественном числе обозначает два и более предмета.

Теперь ты знаешь, что множественное число имён существительных образуется за счёт изменения окончания:

- конфет**а** — конфет**ы**;

- кекс — кекс**ы**;

- яблок**о** — яблок**и**;

- чашк**а** — чашк**и**.

Но попробуй поставить во множественное число слова:

ребёнок — ?
человек — ?
небо — ?
зайчонок — ?

Ответ

ребёнок — дети
человек — люди
небо — небеса
зайчонок — зайчата

**Иногда множественное число имён существительных образуется:**

- изменением всего слова;

- добавлением или изменением суффикса;

- изменением основы слова.

Но у ребят снова возникли вопросы.
— Мистер Фокс, а все ли существительные можно изменить по числам?
Мистер Фокс подвинул к себе сахарницу, поближе поставил печенье и сливки.
— Как вы думаете, существительные сахар, сливки, печенье можно изменить по числам?

Ответ

Некоторые имена существительные имеют форму только единственного числа или только форму множественного числа.

**Какие категории имён существительных имеют только одну форму числа**

| **Имена существительные только в форме единственного числа** | **Имена существительные только в форме множественного числа** |
| Вещественные имена существительные: / бензин, земляника, фарфор | Вещественные имена существительные: / сливки, чернила, дрожжи |
| Отвлечённые имена существительные: / зелень, желтизна, молодость | Отвлечённые имена существительные: / сутки, хлопоты |
| Собственные имена существительные: / Москва, Волга, Россия | Собственные имена существительные: / Альпы, Афины, Лужники |
| Собирательные имена существительные: / родня | Парные предметы: / шорты, ножницы, сани, брюки |
| Существительные на **-мя**: / пламя | Название игр: / прятки, городки, жмурки |
| | Название действий: выборы |

**Проверь себя**

**Задание 1.** Что такое число имён существительных?

**Задание 2.** Все ли имена существительные могут изменяться по числам?

Ответы

**1.** Имена существительные изменяются по числам. То есть они имеют форму единственного и множественного числа. При изменении имени существительного по числам изменяется и его окончание.
Имя существительное в единственном числе обозначает один предмет. Например, окно, стекло, ручка, стол, тетрадь, пенал.
Имя существительное во множественном числе обозначает два и более предмета. Например, окна, стёкла, ручки, столы, тетради, пеналы.
**2.** Некоторые имена существительные имеют только форму единственного числа или только форму множественного числа.
