Правописание сложных имён существительных. Написание пол-, полу-
Предмет: Русский язык
Раздел: Орфография
Источник: https://foxford.ru/wiki/russkiy-yazyk/pravopisanie-slozhnyh-imen-sushchestvitelnyh-napisanie-pol-polu-vpol-
Обновлено: 2026-10-05

Рассмотрим предложенные слова. Прочитаем их. Понаблюдаем и ответим на вопрос: «Как писать сложные существительные?»

Землетрясение, броненосец, северо-восток, пол-лимона, пол-Москвы, полстакана, сбербанк, Санкт-Петербург, лесоруб.

узнать ответ

Сложные имена существительные можно писать как слитно, так и через дефис.

| Пишутся **слитно** | Примеры |
| Сложные существительные, образованные при помощи соединительных гласных **е** и **о** | землекоп, книголюб, лесостепь |
| Сложные существительные с первой иноязычной частью **авиа-**, **авто-**, **аудио-**, **видео-**, **вело-**, **кино-**, **мото-**, **фото-**, **электро-** и подобными, оканчивающимися на гласную | авиамодель, кинопоказ, видеообращение |
| Сложносокращенные существительные всех типов | запчасти, завхоз, МГУ, РФ |
| Пишутся **через дефис** | Примеры |
| Сложные существительные, обозначающие названия промежуточных сторон света | юго‑запад, северо‑восток, северо‑северо‑запад |
| Сложные существительные, состоящие из самостоятельных слов без соединительной гласной | диван-кровать, кресло-качалка, вагон-ресторан |
| Сложные существительные, обозначающие географические названия и состоящие из двух существительных, а также существительных, между которыми в названии есть предлог или союз* | Санкт‑Петербург, Ростов‑на‑Дону, Комсомольск‑на‑Амуре |
| Слова с начальными иноязычными элементами **вице-, лейб-, обер-, унтер-, штаб-, экс-** | экс-жених, вице-адмирал |

*Пишутся слитно существительные, образованные от пишущихся через дефис собственных имён, состоящих из двух частей с начальными прописными буквами. Например: буэносайресцы, йошкаролинцы, костариканцы, лосанджелесцы, ньюйоркцы, ореховозуевцы, уланудэнцы, устькаменогорцы (названия жителей городов и государств).

Часто сложно определить написание иностранного слова, потому что на него влияют два языка: родной и чужой. Заимствование предполагает адаптацию слова в структуре языка-преемника и постепенное приспособление к его языковым нормам. И на этот процесс необходимо время. Поэтому при затруднении в правописании иноязычных имён существительных правильнее всего обратиться к орфографическому словарю.

Существуют сложные существительные с первой частью **пол-**, **полу-**. Чтобы правильно их писать, нужно запомнить правила из таблицы:

| Пишутся **слитно** | Примеры |
| Сложные существительные с первой частью **полу-** | полумесяц, полукруг, полуавтомат |
| Сложные существительные с первой частью **пол-**, после которой следует строчная (маленькая) согласная (кроме **л**) | полчаса, полмагазина, полгорода |
| Пишутся **через дефис** | Примеры |
| Сложные существительные с первой частью **пол-**, после которой следует гласная, согласная **л** или прописная (большая) буква | пол‑лимона, пол‑апельсина, пол‑Москвы |

| **Пишутся слитно** | **Примеры** |
| сложные существительные со второй частью на **-ГРАД, -ГОРОД** | Ленинград, Волгоград, Новгород |
| сложные существительные с глагольной частью на **И** | горицвет, сорвиголова (но: перекати-поле) |
| **Пишутся через дефис** | **Примеры** |
| сложные существительные, обозначающие политические партии, их членов или сторонников | социал-демократия, социал-демократ |
| сложные существительные, обозначающие единицы измерения | грамм-молекула, киловатт-час (но: трудодень) |
| существительные, имеющие в первой части иноязычные элементы вице-, лейб-, обер-, унтер-, штаб-, экс- | вице-президент, обер-мастер, лейб-гвардия, унтер-офицер, штаб-квартира, экс-чемпион |
