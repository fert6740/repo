{**Предлог**} — это служебная часть речи, которая показывает:

Связь между словами (книга на столе)

Отношение в пространстве/времени/причине (пришёл из школы, повторил к уроку)

Предлоги в русском языке делятся на **непроизводные** и **производные**. К первым относят такие предлоги, которые не образованы от других частей речи: к, без, о, в, из-за, через, про и др. Ко второй группе относятся предлоги, образованные от других частей речи или путём соединения двух частей речи: согласно, ввиду, в течение, в завершение, навстречу и др.

Также предлоги делятся на **простые**, состоящие из одного слова (согласно, около) и **составные**, состоящие из двух и более слов (по причине, в соответствии с).

Предлоги пишутся раздельно со словами, к которым они относятся. Важно отличать предлоги от приставок. Для этого необходимо обратить внимание на следующее:

после предлога можно поставить вопрос: на чём? на столе;

предлоги не употребляются при глаголах;

между предлогом и словом, к которому он относится, можно вставить ещё слово: в доме (в большом доме).

Из сочетания двух простых непроизводных предлогов образуются сложные: из-за, из-под, по-за, по-над. Они пишутся через дефис.

| Непроизводные | Производные |
| от существительного | от деепричастия | от наречия |
| в | в заключение | начиная с | впереди |
| к | насчёт | включая | согласно |
| до | в силу | спустя | мимо |
| при | вслед | невзирая на | вдоль |
| без | ввиду | несмотря на | напротив |
| с | в продолжение | исключая | вокруг |
| о | в отношении | благодаря | поперёк |
| над | в течение | исходя из | вблизи |
| под | вследствие | | |
| у | наподобие | | |
| на | в отличие от | | |
| за | в связи с | | |
| от | по направлению | | |
| через | сверх | | |

Наиболее трудные для написания — производные предлоги. Сложность в том, что нужно знать падежную форму слова, следующего за предлогом, и помнить о слитном и раздельном написании.

**Внимание!**

1. Производные предлоги ввиду, вместо, внутри, вроде, вследствие, наперекор, вслед, напротив, навстречу, наподобие, невзирая (на), несмотря (на), насчет пишутся слитно.

2. Производные предлоги в виде, в продолжение, в отличие, в течение, в заключение, в завершение, во избежание, в связи, в силу, в целях, на протяжении пишутся раздельно.

А также их следует научиться отличать от омонимичных сочетаний слов других частей речи. Для этого используем алгоритм:

| Производный предлог | Существительное с предлогом |
| Задаём вопрос |
| Вопрос задаётся ко всему сочетанию: ждать (когда?) в течение года | Вопрос от предлога к существительному: заметил (в чём? где?) в течении реки |
| Попробуем просклонять |
| Невозможно | Существительное, которое входит в состав сочетания, можно просклонять Им.п. течение Род.п. течения Вин.п. течение |
| Пробуем вставить слово между предлогом и существительным |
| Невозможно | Можно вставить нашёл в (быстром) течении реки |

Следует отличать производные предлоги несмотря на и невзирая на от деепричастия. Сравним:

Несмотря на непогоду, волчонок Макс побежал на улицу.

Несмотря на — предлог, можно заменить синонимичным предлогом вопреки.

Не смотря по сторонам, енотик Пётр стал переходить дорогу.

Не смотря — деепричастие: обозначает добавочное действие, можно заменить на не глядя.

Таким образом, подбор синонимичных предлогов может помочь отличить производный предлог от омонимичных сочетаний слов других частей речи, а также понять, как его правильно писать. Обратимся к таблице.

| Производные предлоги | Синонимы | Примеры |
| посередине | посреди | Посередине комнаты мистера Фокса лежал пёстрый ковёр. |
| по причине вследствие ввиду в связи с в силу | из-за, благодаря | Волчонок Макс выглядел бледно вследствие болезни. |
| навстречу | к | Мистер Фокс вышел навстречу своим друзьям. |
| близ в виду вблизи | около | Вблизи дома енотик Пётр увидел бельчонка Беллу. |
| насчёт | о | Енотик Пётр договорился насчёт посещения лекций. |
| в течение в продолжение на протяжении | во время, за | На протяжении двух недель мистер Фокс читал новую книгу. |
