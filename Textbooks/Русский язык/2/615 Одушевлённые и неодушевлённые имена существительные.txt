Одушевлённые и неодушевлённые имена существительные
Предмет: Русский язык
Раздел: Русский язык в начальной школе
Источник: https://foxford.ru/wiki/russkiy-yazyk/odush-neodush-imena
Обновлено: 2026-10-05

**В этой статье ты узнаешь:**

- что такое одушевлённые имена существительные;

- что такое неодушевлённые имена существительные.

**Имя существительное** — это самостоятельная часть речи, которая **обозначает предмет** и отвечает на вопросы **кто? что?**

Дедушка Фокс тоже был школьником. Он любит вспоминать те времена, когда был юным лисёнком и носил при себе карандаш, чтобы записывать свежие мысли.

**Имя существительное может называть:**

| **Людей и животных** | **Предметы, явления, чувства** |
| ⇓ | ⇓ |
| **Кто?** / дедушка, лисёнок, школьник | **Что?** / карандаш, юность, любовь |
| ⇓ | ⇓ |
| **Одушевлённое** / имя существительное | **Неодушевлённое** / имя существительное |

**Одушевлённые имена существительные** называют людей и животных, отвечают на вопрос **кто?**

**Неодушевлённые имена существительные** называют неживые предметы, объекты, явления, чувства, отвечают на вопрос **что?**

**Проверь себя**

**Задание. Распредели имена существительные по двум колонкам:** воробей, рассвет, совесть, осина, енотик, книга, море, белочка, сестрёнка, картина, бабушка, бутерброд, ромашка, пингвин, волчонок, честность, добро.

| **Одушевлённое** / **имя существительное** | **Неодушевлённое** / **имя существительное** |

Ответ

| **Одушевлённое** / **имя существительное (кто?)** | **Неодушевлённое** / **имя существительное (что?)** |
| воробей / енотик / белочка / сестрёнка / бабушка / пингвин / волчонок | рассвет / совесть / осина / книга / море / картина / бутерброд / ромашка / честность / добро |
