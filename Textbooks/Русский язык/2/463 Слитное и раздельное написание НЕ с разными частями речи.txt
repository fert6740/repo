Слитное и раздельное написание НЕ с разными частями речи
Предмет: Русский язык
Раздел: Орфография

Уровни сложности на сайте: Улучшить школьные оценки, Подготовиться к ОГЭ — текст для всех уровней один

Чтобы правильно писать НЕ со словами, необходимо:

1. Знать, к какой **части речи** относится слово с НЕ.

2. **Условия** правописания НЕ со словами **различных частей речи**.

## НЕ пишется слитно

| со всеми словами, которые не употребляются без НЕ | **не**ряха, **не**взрачный, **не**навидеть, **не**годуя, **не**лепо |
| с существительными, полными и краткими прилагательными, наречиями на -О, которые можно в данном контексте заменить синонимом без НЕ | опасный **не**приятель = опасный __враг__ / **не**плохой урожай = __хороший__ урожай / дом **не**высок = дом __низок__ / находиться **не**далеко = находиться __близко__ |
| с полными причастиями, не имеющими зависимых слов | **не**подстриженные кустарники, **не**распечатанное письмо |
| в неопределённых и отрицательных местоимениях без предлога | **не**кто, **не**что, **не**который, **не**кого, **не**чего |
| в отрицательных местоименных наречиях | **не**где, **не**куда, **не**когда, **не**откуда, **не**зачем |
| в приставке НЕДО- с глаголами, деепричастиями, прилагательными и существительными* | суп **недо**соленный, за ребёнком **недо**смотрели, / **недо**едая во время засухи, **недо**сказанность в отношениях, **недо**зрелый фрукт |
| с причастиями (если при них нет других зависимых слов), прилагательными, наречиями на -О, если к ним относятся слова **совершенно, очень, весьма, крайне, чрезвычайно** и т. д., которые усиливают степень качества | поступить __крайне__ **не**осторожно, __весьма__ **не**продуманное предложение. / НО: совершенно **не** продуманное __комиссией__ предложение (есть другое зависимое слово) |

## Обратите внимание!

**Следует отличать приставку НЕДО- от сочетания частицы НЕ с приставкой ДО- в словах.** Сравните:

Мистер Фокс ушёл домой, так и **не** достав билетов на премьеру спектакля.

Мистер Форд сумел достать билет, но **не** досмотрел спектакль до конца и вдруг вышел из зала.

**В данных предложениях слова с частицей НЕ и приставкой ДО- обозначают действия,** **не доведённые до конца, и пишутся с НЕ раздельно.**

Мистер Форд вспомнил, что ушёл из кассы, **недо**платив за билет двадцать рублей.

Кассир расстроился, обнаружив **недо**стачу, но Мистер Форд вовремя вернул деньги.

**В данных предложениях слова с приставкой НЕДО- имеют значение недостаточности по сравнению с нормой и пишутся с НЕ слитно.**

## НЕ пишется раздельно

| с глаголами, деепричастиями и краткими причастиями (за исключением тех, которые без НЕ не употребляются) | **не** спешить, **не** спеша, **не** стрижены (НО: **не**навидеть, **не**доумевая) |
| с краткими прилагательными с оттенком долженствования | **не** рад, **не** должен, **не** согласен, **не** намерен |
| с прилагательными и наречиями в сравнительной степени | **не** выше, **не** умнее, **не** красивее, с **не** меньшим (успехом) |
| с числительными | **не** один, **не** пятьдесят, **не** двое, **не** первый |
| с наречиями (кроме образованных от прилагательных с помощью суффикса -О), а также с неизменяемыми словами, употребляющимися в роли сказуемого | **не** жаль, **не** надо, **не** поздно, **не** жарко, **не** вовремя, **не** впрок, **не** позади, **не** полностью, **не** зазорно, **не** замужем |
| с полными причастиями, если при них есть зависимые слова | **не** сделанное __вовремя__ задание, __так и__ **не** сыгранная музыкальная пьеса |
| со всеми частями речи, если к ним относится противопоставление с союзом А** | **не** длинный, а короткий; **не** высок, __а__ низок; **не** стриженый, __а__ бритый |
| с существительными, прилагательными, наречиями на -О, если при них есть местоимение или наречие с НИ или если НЕ входит в состав усилительных отрицаний **далеко не, вовсе не, отнюдь не** | __ничуть__ **не** красивый, __отнюдь__ **не** дёшево, __далеко__ **не** красавица |
| в отрицательных местоимениях с предлогами | **не** __с__ кем, **не** __для__ кого, **не** __от__ кого, **не** __для__ чего, **не** __с__ чем |
| с любыми словами, которые пишутся через дефис | **не** по‑дружески, **не** юго‑западный, **не** премьер‑министр |

## Обратите внимание!

**Прилагательные или наречия на -О, связанные противительным союзом НО, пишутся с НЕ слитно, если противопоставляются разные признаки:** **не**дорогой, __но__ красивый костюм; **не**громко, __но__ выразительно.
