## Словообразовательная цепочка, словообразовательная пара и родовое гнездо

**Словообразовательная цепочка** — это группа однокоренных слов, которые расположены с учётом последовательности их образования.

Например: белый — белить — побелить — побелка — побелочный.

Каждое последующее слово образовано от предыдущего. От прилагательного белый образован глагол белить. Такие два слова называются **словообразовательной парой**.

**Словообразовательные пары** и **словообразовательные цепочки** могут ветвиться в **родовых гнёздах** однокоренных слов.

**Родовое гнездо** — совокупность всех слов, содержащих общий корень.

| **бел**ый | → бел**изн**а |
| → бел**як** |
| → бел**ок** | → бел**ков**ый |
| → бел**и**ть | → бел**и**ль**н**я / → бел**ил**а / → бел**ил**ь**щик** |
| → **по**бел**и**ть | → **по**бел**к**а | → **по**бел**очн**ый |
| → **по**бел**очк**а |
| → бел**е**ть | → **по**бел**е**ть |
| → бел**оват**ый | → бел**оват**о |
| → бел**оватость** |
| → бел**еньк**ий |

В этом родовом гнезде слово белый является **вершиной гнезда**, оно входит в состав всех других слов и определяет их значение. Ты можешь увидеть здесь словообразовательные пары и словообразовательную цепочку.

## Как составить словообразовательную цепочку

На примере слова безобидный разбери алгоритм составления словообразовательной цепочки:

1. Возьми исходное слово: безобидный.

2. Выдели все морфемы в слове:
[рисунок Рисунки/598-7.png: *безобидный* (слово в рамке, внутри рамки значки морфем)]

3. Подбери словообразовательную пару — однокоренное слово с похожим значением, от которого образовалось слово:
[рисунок Рисунки/598-8.png: *обидный* (слово в рамке, внутри рамки значки морфем)]

4. Определи способ формирования слова: приставочный способ.
[рисунок Рисунки/598-9.png: *обидный* → *безобидный*]

Далее:

1. Теперь исходное слово: обидный.

2. Выдели все морфемы в слове: обидный.

3. Подбери словообразовательную пару:
[рисунок Рисунки/598-10.png: *обида* (слово в рамке, внутри рамки значок)]

4. Определи способ формирования слова: суффиксальный способ.
[рисунок Рисунки/598-11.png: *обида* → *обидный*]

Построй словообразовательную цепочку:

[рисунок Рисунки/598-12.png: *обида* → *обидный* → *безобидный* (каждое слово в рамке, внутри рамок значки морфем)]

Если при составлении словообразовательных цепочек возникают трудности или вопросы, воспользуйся **словообразовательным словарём.**

## **Проверь себя**

Определи вершину родового гнезда.
Каким способом образовано слово хвостик?

[рисунок Рисунки/598-15.png:
хвост →
- хвост-**ик**
- хвост-**ищ**-е (ударение на «и»: хвост-**и́щ**-е)
- хвост-**ат**-ый (ударение на «а»: хвост-**а́т**-ый)
- хвост-**ов**-ой (ударение на «о» в окончании: хвост-**ов**-о́й)
- **бес**-хвóст-ый
- длинн-**о**-хвóст-ый
- коротк-**о**-хвóст-ый
]

Ответ

Вершина словообразовательного гнезда — слово хвост.
Слово хвост**ик** образовано суффиксальным способом.
