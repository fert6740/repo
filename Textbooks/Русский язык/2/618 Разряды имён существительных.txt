**В этой статье ты узнаешь:**

- разряды имён существительных по значению;

- морфологические особенности существительных разных разрядов.

{**Имя существительное**} — это самостоятельная часть речи, которая обозначает предмет и отвечает на вопросы **кто? что?**

Знакомство с некоторыми разрядами по значению имён существительных уже состоялось. Например, **собственные** и **нарицательные** имена существительные.
В свою очередь, нарицательные имена существительные делятся ещё на четыре разряда по значению. Попробуем разобраться:

Сравни выделенные существительные в предложениях. Какие из них обозначают конкретный предмет?

В доме мистера Фокса большой **стол**.
Белочка Белла любит **рисование**.
Енотик Пётр собрал в беседке **детвору**.
Волчонок Макс предлагает всем **молоко**.

Ответ

Конкретный предмет обозначает только существительное — **стол**. Существительное **рисование** обозначает то, что нельзя потрогать руками, то есть отвлечённое понятие.
**Детвора** состоит из нескольких лиц, которые собрали вместе.
А **молоко** — это вещество.

### **Разряды имён существительных по значению**

- конкретные,

- отвлечённые (абстрактные),

- собирательные,

- вещественные.

{**Конкретные существительные**} — это названия материальных предметов или явлений реального мира, которые можно увидеть или потрогать: стол, рука, трактор, поле, дорога, белочка, ухо.

Имеют форму ед. ч. и мн. ч.: рука — руки, ухо — уши, стол — столы.
Они сочетаются с количественными числительными: два трактора, пять сеялок, три дороги, десять белочек.

{**Отвлечённые (абстрактные)**} существительные обозначают нематериальные объекты, явления, свойства, качество, действие, состояние: радость, доверчивость, честность, сонливость, храбрость, белизна, эхо.

Имеют форму только ед. ч.
Не сочетаются с количественными числительными.

{**Собирательные существительные**} называют совокупность однотипных сходных лиц или предметов как единое целое: человечество, крестьянство, молодёжь, листва, березняк, родня, вороньё, детвора, мошкара, аппаратура.

Имеют форму только ед. ч.
Не сочетаются с количественными числительными.

{**Вещественные существительные**} — это названия однородных по своему составу веществ, поддающихся делению, измерению, но не счёту. Например:

- пищевые продукты — хлеб, соль, молоко;

- полезные ископаемые — нефть, уголь, железо;

- сельскохозяйственные культуры — рожь, горох;

- стройматериалы — бетон, черепица.

Вещественные имена существительные не изменяются по числам. Они употребляются либо только в форме ед. ч., либо только в форме мн.ч.
Форма только ед. ч.: морковь, картофель, рожь, молоко, клубника, сметана.
Форма только мн.ч.: опилки, белила, сливки, духи, чернила.

### **Проверь себя**

**Задание.** Соедини группы существительных и название разряда по значению.

| Конкретные | Движение, любовь, учёба, трудности, уважение, сумерки, сладость |
| Отвлечённые (абстрактные) | Капуста, фасоль, сгущёнка, цемент, мука, манка, гречка, гипс, олово |
| Собирательные | Школа, ученик, учитель, ручка, енот, стул, телефон, автомобиль, дерево |
| Вещественные | Юношество, учительство, бельё, беднота, осинник, студенчество |

| Конкретные | Школа, ученик, учитель, ручка, енот, стул, телефон, автомобиль, дерево |
| Отвлечённые (абстрактные) | Движение, любовь, учёба, трудности, уважение, сумерки, сладость |
| Собирательные | Юношество, учительство, бельё, беднота, осинник, студенчество |
