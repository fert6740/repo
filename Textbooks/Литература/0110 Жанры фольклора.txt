# Что такое жанры фольклора

**ЖА́НРЫ ФОЛЬКЛО́РА** — разновидность художественных произведений в рамках одного из трёх родов фольклора (эпоса, лирики или драмы) или на их стыке.

# Виды фольклорных жанров

## Эпические фольклорные жанры:

| **Былина** | «Вольга и Микула Селянинович», «Алёша Попович и Тугарин Змей», «Садко». |
| **Историческая песня** | «Авдотья Рязаночка», «Взятие Казани», «Казнь стрельцов». |
| **Сказка** | Волшебные сказки — «Василиса Премудрая», «Аленький цветочек»; сказки о животных — «Коза-дереза», «Петушок — золотой гребешок»; бытовые сказки — «Дочь-семилетка», «Чего на свете не бывает…». |
| **Предание** | «Предание о Петре Первом». |
| **Сказ** | «Артёмов ключ», «Еремеево слово». |

## Лирические фольклорные жанры:

- календарные обрядовые песни («Завью венки»);

- семейные обрядовые песни («Во горнице, во светлице…»);

- колыбельные («Баю-баюшки-баю, // Не ложися на краю…»);

- семейные песни («На улице воробушек…», «Лучинушка»);

- любовные песни («Раз, два — люблю тебя…», «Миленький ты мой…»);

- причитания («Плач невесты», «Причитание по отцу»);

- частушки («Ой, маменька, тошно, // Хвораю нарочно: // Пеки пышки на меду — // Я милого приведу»);

- пословицы;

- поговорки.

## Драматические фольклорные жанры:

- народная драма («Царь Максимильян», «Театр Петрушки»).
